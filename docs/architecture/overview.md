# 제품군 구조 지도

> 저장소 전체 구조의 요약 지도다. 상세 트리·근거·결정은 `frameworks/ui/plan/05_아키텍처/01_XKXK_저장소구조.md` 와 UADR-0001(`frameworks/ui/plan/90_결정관리/02_결정기록_ADR.md`)이 정본이다.

## 층
| 층 | 경로 | 내용 |
|---|---|---|
| 프레임워크 | `frameworks/` | 제품군이 함께 쓰는 기반. 첫 영역은 별별UI(`frameworks/ui`) |
| 라이브러리 | `libraries/` | 공용 비 UI 라이브러리(자리) |
| 모듈 | `modules/` | 업무 모듈(자리) |
| 앱 | `apps/` | 모듈을 조립한 실행 앱(자리) |
| 도구 | `tooling/` | 저장소 전체 개발 도구(자리) |

## 다른 저장소
- Pd 제품(업무 기능·서버·DB·Pd 정본 문서)은 별도 Pd 저장소(`/mnt/c/DATA/Project/Pd`)에 남는다. 이 저장소에는 `apps/pd` 를 두지 않는다.

## 원문
- 구조를 논의한 대화 원문은 `source/` 에 있다(2026-11-24).
