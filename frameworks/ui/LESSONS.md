> 옮긴 항목 안의 경로는 Pd 저장소 기준이다(`poc/ui/` 는 이 저장소의 `frameworks/ui/` 에 해당한다).

7. **OS 셸 UI 클릭은 대상 PID 를 사전 확정하고 사용자 창 전수 대조를 하면 측정할 수 있었다.** Q14 ③ 스냅은 처음에 측정 불가로 이월했으나, 시험 축이 플라이아웃 소유(explorer PID·창제목)를 클릭 전에 확정해 첫 시도부터 지정하고 사용자 창 전체를 전후 대조하자 가드 차단 0·사용자 창 변화 0 으로 PASS 를 얻었다(D-C2-56). 셸 소유 팝업이 걸린 시험은 이 두 가지를 먼저 갖춘 뒤 측정한다.
8. **소유 창(owned window)의 z 순서는 OS 가 정한다.** SDI 그림자 창을 SDI 의 소유 창(GW_OWNER=SDI)으로 만들었더니, 활성화 뒤 OS 가 그림자를 항상 SDI 바로 앞에 두어 B6 z 순서 기준을 어겼다(D-C2-59). 비소유 창으로 바꾸고 SetWindowPos(hWndInsertAfter=SDI)로 직접 뒤에 걸자 통과했다. 창 뒤에 붙는 보조 창은 처음부터 비소유 창으로 설계하고, 대신 닫힘 정리(WM_DESTROY 외 안전망)를 직접 챙긴다.

12. **gate 에 회귀 범위를 잘못 적었다.** Q2 gate 에 화면 안 보정(MDI-12) 회귀가 포함된 것처럼 적혔다. 실제로는 기존 retest 도구에 그 항목이 없어 실행한 적이 없었다(D-C2-64). 정정해 측정 한계와 이월 항목(15항목째)으로 돌렸다. gate 에 회귀 범위를 적을 때는 실행한 도구의 항목 목록·로그와 하나씩 대조해, 실행 로그가 있는 항목만 적는다.
