## IUiIconRegistry

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiIconRegistry`

아이콘 키를 그림 정의로 해석하는 레지스트리다. `IUiAppContext` 와 `IUiModuleContext` 의 Icons 로 얻는다.

> 프레임워크만 구현한다. 소비자는 이 인터페이스를 구현하지 않는다(멤버 추가가 호환 변경이다). 앞으로의 확장(공급자 변경 알림·아이콘 격자·다색 등)은 멤버 추가로만 연다.
> 해석 순서: ① 명시 등록(`Add`) ② 공급자(`Providers` 순서) — 첫 일치를 돌려준다. 명시 등록이 공급자 키를 가리는 것은 정상 재정의이며 진단이 없다. 명시 키를 `Remove` 하면 공급자 값이 다시 보인다.
> 예약(T-RESERVED): 아이콘 키는 예약하지 않는다. 프레임워크는 아이콘을 명시 등록하지 않고 공급자로만 더한다. 공급자 Id 의 예약 접두어(`UiRegistryOwners.ReservedPrefix`)는 프레임워크 주체만 쓸 수 있다(아니면 XKUI0206).
> 등록 정책(T-POLICY): P1 `UiIconOptions.Replace`=true 인데 기존 명시 등록이 없으면 새로 등록한다(Added). P2 `Remove`·`RemoveProvider` 는 그 항목을 등록한 주체만 할 수 있다(아니면 XKUI0207, 지우지 않음). Replace=true 교체는 주체와 무관하게 허용되고 등록 주체·제거 권한은 교체한 주체로 옮긴다. P4 빌더 Build 가 끝난 뒤 모듈이 붙잡아 둔 레지스트리로 등록하면 실행 중 등록과 같다 — 즉시 검사, 진단은 앱 진단 모음, 예외 없음.
> 규칙 위반은 예외 대신 진단(XKUI02xx)을 남기고 false 를 돌려준다. 인자가 null 이면 `ArgumentNullException`. `Changed` 는 잠금 밖에서 발생한다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Add` | `Add(string! key, System.Action<UiIconOptions!>! configure) -> bool` | 아이콘을 명시 등록한다(또는 Replace=true 로 교체한다). |
| `AddGeometry` | `AddGeometry(string! key, string! pathData) -> bool` | SVG path 문법 그림 데이터로 아이콘을 명시 등록한다. `Add(key, o => o.PathData = pathData)` 와 같다. |
| `AddProvider` | `AddProvider(UiIconProvider! provider) -> bool` | 아이콘 공급자를 맨 앞(가장 높은 우선순위)에 더한다. |
| `Changed` | `Changed -> System.EventHandler<UiRegistryChangedEventArgs!>?` | 명시 등록·공급자가 바뀌면 발생한다(잠금 밖). 모르는 `UiRegistryChangeKind` 값은 전체 변경으로 본다. |
| `Contains` | `Contains(string! key) -> bool` | 키를 해석할 수 있는지(명시 등록 또는 공급자) 확인한다. |
| `Keys` | `Keys.get -> System.Collections.Generic.IReadOnlyList<string!>!` | 해석 가능한 전체 키(명시 등록 + 공급자, 중복 제거, Ordinal 정렬). 호출 시점의 사본이다. |
| `Providers` | `Providers.get -> System.Collections.Generic.IReadOnlyList<UiIconProvider!>!` | 등록된 공급자(우선순위 높은 순 — 나중에 더한 공급자가 앞, 기본 생성 공급자 `UiRegistryOwners.Generated` 가 맨 끝). 호출 시점의 사본이다. |
| `Remove` | `Remove(string! key) -> bool` | 명시 등록 아이콘을 제거한다. 공급자 키만 있으면 false. |
| `RemoveProvider` | `RemoveProvider(string! providerId) -> bool` | 공급자를 Id 로 제거한다. |
| `TryGet` | `TryGet(string! key, out UiIconDefinition? icon) -> bool` | 키를 해석해 아이콘 정의를 얻는다. 돌려주는 정의의 Owner 는 등록 주체로 채워져 있다. |

## UiIconProvider

- 종류: `abstract class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiIconProvider`

키 묶음을 한꺼번에 공급하는 아이콘 공급자의 기반 클래스다. 소비자가 상속해 만든다.

> `IUiIconRegistry.AddProvider(UiIconProvider)` 로 등록한다. 해석 순서는 명시 등록이 먼저이고, 그다음 `IUiIconRegistry.Providers` 순서(나중에 더한 공급자가 앞)대로 `TryGetIcon` 를 묻는다. 공급자가 돌려준 정의의 등록 주체는 레지스트리가 이 공급자의 `Id` 로 맞춘다.
> 등록 규칙: `Id` 가 비었거나 같은 Id 공급자가 이미 있으면 XKUI0205, 프레임워크 아닌 주체가 예약 접두어(`UiRegistryOwners.ReservedPrefix`) Id 를 쓰면 XKUI0206 진단을 남기고 등록하지 않는다.
> 구현 규칙: `Id` 와 `Keys` 는 등록 뒤 바뀌지 않는 것으로 본다. 여러 스레드에서 불릴 수 있으므로 읽기 전용 자료로 답하는 것을 권한다.
> 확장 규칙(UADR-0009): 이 클래스에는 추상 멤버를 추가하지 않는다. 새 기능(예 키 목록 변경 알림)은 기본 구현이 있는 `virtual` 멤버로만 더해 기존 파생 클래스의 소스·바이너리 호환을 지킨다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Id` | `abstract Id.get -> string!` | 공급자 Id(Ordinal 비교, 레지스트리 안에서 유일). 공급자 아이콘의 등록 주체로도 쓰인다. |
| `Keys` | `abstract Keys.get -> System.Collections.Generic.IReadOnlyCollection<string!>!` | 이 공급자가 답할 수 있는 아이콘 키 전체. |
| `TryGetIcon` | `abstract TryGetIcon(string! key, out UiIconDefinition? icon) -> bool` | 키에 해당하는 아이콘 정의를 찾는다. |
| `UiIconProvider` | `UiIconProvider() -> void` | 파생 클래스용 생성자. |

## UiIconDefinition

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiIconDefinition`

아이콘 1개의 정의(불변).

> 공개 생성자가 없다. `FromPathData(string, string)` 또는 `FromResource(string, string)` 로 만든다. 팩터리로 만든 값의 `Owner` 는 빈 문자열이고, 레지스트리가 돌려주는 값은 등록 주체를 채운 사본이다.
> `Kind` 가 `UiIconKind.PathData` 면 `PathData` 만, `UiIconKind.Resource` 면 `ResourceKey` 만 값이 있다.
> 확장 규칙: 새 원천은 `UiIconKind` 값과 새 팩터리 추가로만 넓힌다(기존 팩터리 서명 불변).

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `FromPathData` | `static FromPathData(string! key, string! pathData) -> UiIconDefinition!` | SVG path 문법 그림 데이터로 아이콘 정의를 만든다. |
| `FromResource` | `static FromResource(string! key, string! resourceKey) -> UiIconDefinition!` | Avalonia 리소스 키로 아이콘 정의를 만든다. |
| `Description` | `Description.get -> string?` | 개발자용 설명. 없으면 null. |
| `Key` | `Key.get -> string!` | 아이콘 키. |
| `Kind` | `Kind.get -> UiIconKind` | 그림 원천 종류. 모르는 값이면 그리지 못하는 아이콘으로 보고 폴백한다. |
| `Owner` | `Owner.get -> string!` | 등록 주체(`UiRegistryOwners` 상수·모듈 ID·공급자 Id). 팩터리로 막 만든 값은 빈 문자열이다. |
| `PathData` | `PathData.get -> string?` | SVG path 문법 그림 데이터. `Kind` 가 `UiIconKind.PathData` 가 아니면 null. |
| `ResourceKey` | `ResourceKey.get -> string?` | 리소스 키. `Kind` 가 `UiIconKind.Resource` 가 아니면 null. |

## UiIconOptions

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiIconOptions`

`IUiIconRegistry.Add(string, System.Action)` 에 쓰는 아이콘 등록 옵션.

> `PathData` 와 `ResourceKey` 는 정확히 하나만 채워야 한다. 둘 다 비었거나 둘 다 채우면 XKUI0203 진단을 남기고 등록하지 않는다.
> 확장 규칙: 새 입력은 기본값이 이전 동작과 같은 속성 추가로만 넓힌다(Add 서명은 바꾸지 않는다).

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Description` | `Description.get -> string?` | 개발자용 설명(선택). |
| `Description` | `Description.set -> void` | 개발자용 설명(선택). |
| `PathData` | `PathData.get -> string?` | SVG path 문법 그림 데이터. 좌표는 24 격자 기준이다(메뉴 아이콘·창 아이콘의 현재 그리기 기준). |
| `PathData` | `PathData.set -> void` | SVG path 문법 그림 데이터. 좌표는 24 격자 기준이다(메뉴 아이콘·창 아이콘의 현재 그리기 기준). |
| `Replace` | `Replace.get -> bool` | 같은 키의 명시 등록을 교체할지 여부. 기본 false. |
| `Replace` | `Replace.set -> void` | 같은 키의 명시 등록을 교체할지 여부. 기본 false. |
| `ResourceKey` | `ResourceKey.get -> string?` | Avalonia 리소스 키. 테마별 값을 둘 수 있으며, 해석 시 리소스에서 Geometry 를 찾는다. |
| `ResourceKey` | `ResourceKey.set -> void` | Avalonia 리소스 키. 테마별 값을 둘 수 있으며, 해석 시 리소스에서 Geometry 를 찾는다. |
| `UiIconOptions` | `UiIconOptions() -> void` | 빈 옵션을 만든다. |

## UiIconKind

- 종류: `enum` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiIconKind`

아이콘 정의의 그림 원천 종류.

> 값이 추가될 수 있다. 모르는 값을 받으면 그리지 못하는 아이콘으로 보고 폴백한다.
> 값은 끝에만 추가하고 기존 숫자는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `PathData` | `PathData = 0 -> UiIconKind` | SVG path 문법 문자열(`UiIconDefinition.PathData`). |
| `Resource` | `Resource = 1 -> UiIconKind` | Avalonia 리소스 키(`UiIconDefinition.ResourceKey`) — 테마별 값을 둘 수 있다. |
