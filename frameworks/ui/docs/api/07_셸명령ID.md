## ShellCommandIds

- 종류: `static class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.ShellCommandIds`

프레임워크가 `IUiCommandRegistry` 에 기본으로 등록하는 셸 명령의 ID 다.

> 모든 값은 프레임워크 예약 접두어 `UiRegistryOwners.ReservedPrefix`("xkxk.")로 시작한다. 소비자는 이 ID 로 명령을 실행하거나 `UiCommandOptions.Replace` 로 동작을 바꿀 수 있지만, 예약 접두어로 시작하는 새 ID 를 만들 수는 없다(XKUI0308). 확장 규칙: 새 기본 명령은 상수를 추가하고 `All` 의 끝에 덧붙인다. 기존 상수의 이름·값·순서는 바꾸지 않는다.
