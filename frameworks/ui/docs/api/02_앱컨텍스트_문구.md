## IUiAppContext

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiAppContext`

앱 전역 UI 상태에 닿는 진입점이다. `XkxkUi` 의 Current 로 얻는다.

> 프레임워크만 구현한다. 소비자는 이 인터페이스를 구현하지 않는다. 확장 규칙: 뒤 batch 에서 멤버를 추가만 한다(제거·서명 변경 금지). 옛 정적 접근자(App.MainViewModel·App.Shell·ViewRegistry.Current·Loc.Instance)는 이 컨텍스트로 위임한다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Commands` | `Commands.get -> IUiCommandRegistry!` | 명령 레지스트리. null 이 아니다. |
| `Diagnostics` | `Diagnostics.get -> UiDiagnostics!` | 앱 수준 진단 모음(비 null, 프로세스 1개). |
| `Icons` | `Icons.get -> IUiIconRegistry!` | 아이콘 레지스트리. null 이 아니다. |
| `Localization` | `Localization.get -> IUiLocalizer!` | 문구 서비스. null 이 아니다. |
| `MainViewModel` | `MainViewModel.get -> xkxk.frameworks.ui.shell.ViewModels.MainViewModel?` | 주 화면 모델. 주 창이 만들어지기 전에는 null. |
| `Menus` | `Menus.get -> IUiMenuRegistry!` | 메뉴 레지스트리. null 이 아니다. |
| `Monitors` | `Monitors.get -> xkxk.frameworks.ui.shell.ViewModels.MonitorMenuViewModel!` | 모니터 메뉴 화면 모델. null 이 아니다. |
| `RegisterViews` | `RegisterViews(xkxk.frameworks.ui.shell.IViewRegistry! views) -> void` | 화면 등록부를 등록한다. 다시 부르면 교체한다. |
| `Settings` | `Settings.get -> xkxk.frameworks.ui.shell.Theming.UiSettings!` | UI 설정(테마·글자 크기·폰트 등). null 이 아니다. |
| `Shell` | `Shell.get -> xkxk.frameworks.ui.shell.Docking.IShellCommands?` | 셸 명령. 셸이 준비되기 전에는 null. |
| `Themes` | `Themes.get -> xkxk.frameworks.ui.shell.Theming.ThemeCatalog!` | 색 테마 목록·선택. null 이 아니다. |
| `Tour` | `Tour.get -> xkxk.frameworks.ui.shell.Tour.TourCatalogData!` | 도움말 투어 카탈로그. null 이 아니다. |
| `Views` | `Views.get -> xkxk.frameworks.ui.shell.IViewRegistry!` | 등록된 화면 등록부. |

## IUiLocalizer

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiLocalizer`

현재 언어로 UI 문구를 찾아 주는 서비스다. `IUiAppContext.Localization` 으로 얻는다.

> 프레임워크만 구현한다. 소비자는 이 인터페이스를 구현하지 않는다. 확장 규칙: 최소 표면만 공개한다. 진단 멤버(전체 키 목록·누락 키 목록)는 넣지 않으며, 필요해지면 뒤 batch 에서 멤버를 추가만 한다(제거·서명 변경 금지). 언어가 바뀌면 `LanguageChanged` 와 `INotifyPropertyChanged.PropertyChanged` 가 발생한다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Format` | `Format(string! key, params object?[]! args) -> string!` | 키의 문구에 `args` 를 자리표시({0} 등)로 채워 돌려준다. |
| `Get` | `Get(string! key) -> string!` | 키의 현재 언어 문구를 돌려준다. 없는 키는 null 대신 대체 문자열을 돌려준다. |
| `HasKey` | `HasKey(string! key) -> bool` | 현재 사전에 키가 있으면 true. |
| `Language` | `Language.get -> string!` | 현재 언어 코드(예 "ko"). 지원하지 않는 코드를 넣었을 때의 처리는 구현이 정한다. |
| `Language` | `Language.set -> void` | 현재 언어 코드(예 "ko"). 지원하지 않는 코드를 넣었을 때의 처리는 구현이 정한다. |
| `LanguageChanged` | `LanguageChanged -> System.Action?` | 현재 언어가 바뀐 뒤 발생한다. |
| `Languages` | `Languages.get -> System.Collections.Generic.IReadOnlyList<UiLanguage!>!` | 지원 언어 목록. 첫 항목이 기본 언어다. null 이 아니다. |
| `Observe` | `Observe(string! key) -> System.IObservable<string!>!` | 키 문구를 관찰한다. 구독 즉시 현재 값을 내고, 언어가 바뀔 때마다 새 값을 낸다. |
| `this[]` | `this[string! key].get -> string!` | 키의 현재 언어 문구. `Get(string)` 과 같다. |

## UiLanguage

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiLanguage`

UI 가 지원하는 언어 1건(코드와 표시 이름).

> `IUiLocalizer.Languages` 의 항목이다. 튜플 대신 클래스로 두어 뒤에 정보를 더할 수 있게 했다. 확장 규칙: 새 정보는 생성자 오버로드와 속성 추가로만 넓힌다(기본값 파라미터 금지).

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Code` | `Code.get -> string!` | 언어 코드(예 "ko", "en"). |
| `Deconstruct` | `Deconstruct(out string! code, out string! name) -> void` | 코드와 이름으로 분해한다(`var (code, name) = language;`). |
| `Name` | `Name.get -> string!` | 사용자에게 보일 언어 이름. |
| `UiLanguage` | `UiLanguage(string! code, string! name) -> void` | 언어를 만든다. |
