# 05 메뉴 — 공개 API 명세

## IUiMenuRegistry

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiMenuRegistry`

메뉴 항목을 ID 로 등록·교체·제거·이동·숨김하고 표시 상태를 계산하는 레지스트리다. 앱 전역은 `IUiAppContext.Menus`, 모듈 구성 중에는 `IUiModuleContext.Menus` 로 얻는다.

> 프레임워크만 구현한다. 소비자는 이 인터페이스를 구현하지 않는다.
> 등록 주체: 모듈 컨텍스트에서 얻은 레지스트리는 그 모듈 ID 를, 앱 컨텍스트에서 얻은 레지스트리는 `UiRegistryOwners.App` 를 등록 주체(`UiMenuItemDefinition.Owner`)로 기록한다. 셸 기본 메뉴의 주체는 `UiRegistryOwners.Shell` 이다. 같은 저장소를 보므로 어느 쪽에서 등록해도 모두에게 보인다.
> 예약 접두어: `UiRegistryOwners.ReservedPrefix`("xkxk.")로 시작하는 ID 는 프레임워크가 쓴다. 프레임워크가 아닌 주체가 아직 없는 예약 ID 를 새로 만들면 등록하지 않고 진단(XKUI0407)을 남긴다. 이미 있는 예약 ID(`ShellMenuIds`)를 `UiMenuItemOptions.Replace` 로 바꾸는 것(재정의)은 허용한다.
> 등록·교체·제거 정책: Replace=true 인데 기존 항목이 없으면 새로 등록한다(P1). 제거는 그 항목을 등록한 주체만 할 수 있다(P2, 다른 주체면 XKUI0408). 교체는 주체와 무관하게 허용하며, 부모가 같으면 항목의 자리를 유지한다(P3, 부모를 바꾼 교체는 `UiMenuItemOptions.Replace` 참고). 빌드가 끝난 뒤 모듈이 붙잡아 둔 레지스트리로 등록하면 실행 중 등록과 같다(P4 — 즉시 검사, 진단은 `IUiAppContext.Diagnostics`, 예외 없음). 이동(`Move`)과 숨김(`SetHidden`)은 항목을 지우지 않으므로 주체와 무관하게 허용하며 등록 주체를 바꾸지 않는다.
> 규칙 위반은 예외 대신 진단(XKUI04xx)을 남기고 false 를 돌려준다. 빌드 도중의 위반은 빌더의 `UiErrorPolicy` 를 따른다. 인자가 null 이면 `ArgumentNullException`(`GetChildren` 의 null 은 최상위를 뜻한다).
> 스레드: UI 스레드에서 부른다. 레지스트리는 대리자 실행 스레드를 옮기지 않는다. `Changed` 는 내부 잠금 밖에서 발생하며 구독자 예외는 삼키지 않는다.
> 확장 규칙(UADR-0009): 앞으로의 기능(표시 상태 재평가 요청·메뉴 묶음 이동 등)은 멤버 추가와 옵션 객체(`UiMenuItemOptions`·`UiMenuPlacementOptions`) 속성 추가로만 연다. 기존 멤버의 서명·의미는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Add` | `Add(string! id, System.Action<UiMenuItemOptions!>! configure) -> bool` | 메뉴 항목을 등록한다(또는 `UiMenuItemOptions.Replace`=true 로 교체한다). |
| `Changed` | `Changed -> System.EventHandler<UiRegistryChangedEventArgs!>?` | 항목이 등록·교체·제거·이동되거나 숨김 상태가 바뀌면 발생한다. `UiRegistryChangedEventArgs.Id` 는 메뉴 ID 다. |
| `Contains` | `Contains(string! id) -> bool` | 메뉴 항목이 등록돼 있는지 확인한다. 숨긴 항목도 등록돼 있으면 true 다. |
| `GetChildren` | `GetChildren(string? parentId) -> System.Collections.Generic.IReadOnlyList<UiMenuItemDefinition!>!` | 부모 바로 아래 항목의 사본을 보이는 순서로 돌려준다. 숨긴 항목도 들어 있다. |
| `GetState` | `GetState(string! id, UiMenuSurface surface) -> UiMenuItemState!` | 항목의 지금 표시 상태를 계산한다. 화면은 메뉴를 열 때마다 부른다. |
| `Items` | `Items.get -> System.Collections.Generic.IReadOnlyList<UiMenuItemDefinition!>!` | 등록된 항목 전체의 사본. 트리 깊이 우선 순서(부모 다음에 그 자식들)이며 숨긴 항목도 들어 있다. |
| `Move` | `Move(string! id, System.Action<UiMenuPlacementOptions!>! configure) -> bool` | 항목의 부모나 자리를 바꾼다. 하위 메뉴는 자식과 함께 옮긴다. 등록 주체와 무관하게 허용한다. |
| `Remove` | `Remove(string! id) -> bool` | 메뉴 항목을 제거한다. 하위 메뉴는 자식 전원이 같은 주체일 때만 자식째 제거한다. |
| `SetHidden` | `SetHidden(string! id, bool hidden) -> bool` | 항목을 숨기거나 다시 보인다. 항목은 지우지 않으며 등록 주체와 무관하게 허용한다. |
| `TryGet` | `TryGet(string! id, out UiMenuItemDefinition? item) -> bool` | 메뉴 항목 정의를 찾는다. |

## UiMenuItemDefinition

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiMenuItemDefinition`

`IUiMenuRegistry` 에 등록된 메뉴 항목 1건의 정의다. 등록 시점 옵션의 사본이며 바뀌지 않는다.

> 공개 생성자가 없다. 프레임워크(레지스트리)만 만든다.
> 이동·숨김은 레지스트리 안의 정의를 새 사본으로 바꾼다. 이미 받은 정의는 바뀌지 않으므로 최신 값은 `IUiMenuRegistry.TryGet` 으로 다시 얻는다.
> 확장 규칙: 새 정보는 읽기 전용 속성 추가로만 넓힌다. 기존 속성의 의미는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `AutomationId` | `AutomationId.get -> string!` | 화면 항목·모바일 서랍 항목의 자동화 이름. 옵션에 주지 않았으면 "menu." 뒤에 메뉴 ID 를 붙인 값이다. |
| `CommandId` | `CommandId.get -> string?` | 실행할 명령 ID(`IUiCommandRegistry` 의 ID). 없으면 null. |
| `CommandParameter` | `CommandParameter.get -> object?` | 명령에 넘길 값. 없으면 null. 객체 자체는 복사하지 않고 참조를 보관한다. |
| `HasToolTip` | `HasToolTip.get -> bool` | 툴팁 대리자가 있는지. |
| `HasVisibilityCondition` | `HasVisibilityCondition.get -> bool` | 표시 조건 대리자가 있는지. |
| `Icon` | `Icon.get -> string?` | 아이콘 키(`IUiIconRegistry` 의 키). 없으면 null(명령 아이콘을 쓴다). |
| `Id` | `Id.get -> string!` | 메뉴 ID. |
| `IsHidden` | `IsHidden.get -> bool` | `IUiMenuRegistry.SetHidden` 으로 숨긴 항목인지. |
| `Kind` | `Kind.get -> UiMenuItemKind` | 항목 종류. 화면은 모르는 값을 그리지 않는다. |
| `Mobile` | `Mobile.get -> UiMenuMobileDefinition!` | 모바일형 투영 힌트. null 이 아니다. |
| `Owner` | `Owner.get -> string!` | 등록 주체. 셸 기본 메뉴는 `UiRegistryOwners.Shell`, 모듈이 등록하면 모듈 ID, 실행 중 앱이 등록하면 `UiRegistryOwners.App`. |
| `Parent` | `Parent.get -> string?` | 부모 메뉴 ID. 최상위면 null. |
| `Section` | `Section.get -> string?` | 화면이 동적으로 채우는 섹션 키. 없으면 null. |
| `Title` | `Title.get -> string?` | 제목(있으면 문구 키보다 먼저 쓴다). 없으면 null. |
| `TitleKey` | `TitleKey.get -> string?` | 제목 문구 키. 없으면 null. |

## UiMenuItemKind

- 종류: `enum` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiMenuItemKind`

메뉴 항목의 종류.

> 값이 추가될 수 있다. 화면은 모르는 값의 항목을 그리지 않는다.
> 값은 끝에만 추가하고 기존 숫자는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Command` | `Command = 0 -> UiMenuItemKind` | 명령을 실행하는 항목(`UiMenuItemOptions.CommandId` 필수). |
| `Section` | `Section = 3 -> UiMenuItemKind` | 화면이 `UiMenuItemOptions.Section` 키로 내용을 채우는 영역. |
| `Separator` | `Separator = 2 -> UiMenuItemKind` | 구분선. |
| `Submenu` | `Submenu = 1 -> UiMenuItemKind` | 자식 항목을 담는 하위 메뉴. 다른 항목의 부모가 될 수 있는 유일한 종류다. |

## UiMenuItemState

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiMenuItemState`

> 공개 생성자가 없다. 프레임워크(레지스트리)만 만든다.
> 등록되지 않은 ID 를 물으면 `IsVisible` 이 false 인 빈 상태를 돌려준다(예외 없음).
> 확장 규칙: 새 정보는 읽기 전용 속성 추가로만 넓힌다. 기존 속성의 의미는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Gesture` | `Gesture.get -> string?` | 단축키 표시 문자열(명령의 단축키). 없으면 null. |
| `Icon` | `Icon.get -> string?` | 아이콘 키. 항목 아이콘이 없으면 명령 아이콘이다. 둘 다 없으면 null. |
| `IsEnabled` | `IsEnabled.get -> bool` | 누를 수 있는지. 명령 항목은 명령의 실행 가능 여부이고(명령이 없으면 false), 하위 메뉴·섹션 항목은 true 다. |

| `Title` | `Title.get -> string?` | 표시 제목. 항목 제목, 항목 문구 키의 문구, 명령 제목 순서에서 처음 있는 값이다. 없으면 null. |
| `ToolTip` | `ToolTip.get -> string?` | 툴팁 대리자의 결과. 대리자가 없거나 예외를 던지면 null. |

## UiMenuMobileDefinition

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiMenuMobileDefinition`

> 공개 생성자가 없다. 프레임워크(레지스트리)만 만든다. 등록 뒤에 옵션 객체를 바꿔도 이 값은 바뀌지 않는다.

> 확장 규칙: 새 정보는 읽기 전용 속성 추가로만 넓힌다. 기존 속성의 의미는 바꾸지 않는다.

|---|---|---|
