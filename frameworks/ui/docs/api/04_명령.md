## IUiCommandRegistry

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiCommandRegistry`

명령을 ID 로 등록·교체·제거·실행하는 레지스트리다. 앱 전역은 `IUiAppContext.Commands`, 모듈 구성 중에는 `IUiModuleContext.Commands` 로 얻는다.

> 프레임워크만 구현한다. 소비자는 이 인터페이스를 구현하지 않는다.
> 등록 주체: 모듈 컨텍스트에서 얻은 레지스트리는 그 모듈 ID 를, 앱 컨텍스트에서 얻은 레지스트리는 `UiRegistryOwners.App` 를 등록 주체(`UiCommandDefinition.Owner`)로 기록한다. 같은 저장소를 보므로 어느 쪽에서 등록해도 모두에게 보인다.
> 예약 접두어: `UiRegistryOwners.ReservedPrefix`("xkxk.")로 시작하는 ID 는 프레임워크가 쓴다. 프레임워크가 아닌 주체가 아직 없는 예약 ID 를 새로 만들면 등록하지 않고 진단(XKUI0308)을 남긴다. 이미 있는 예약 ID 를 `UiCommandOptions.Replace` 로 바꾸는 것(재정의)은 허용한다. 그래서 프레임워크가 다음 판에 기본 명령을 더해도 소비자 등록과 충돌하지 않는다.
> 등록·교체·제거 정책: Replace=true 인데 기존 명령이 없으면 새로 등록한다(P1). 제거는 그 명령을 등록한 주체만 할 수 있다(P2, 다른 주체면 XKUI0309). 교체는 주체와 무관하게 허용하며 `Commands` 안의 자리를 유지한다(P3). 제거 뒤 다시 등록하면 맨 뒤에 붙는다. 빌드가 끝난 뒤 모듈이 붙잡아 둔 레지스트리로 등록하면 실행 중 등록과 같다(P4 — 즉시 검사, 진단은 `IUiAppContext.Diagnostics`, 예외 없음).
> 스레드: UI 스레드에서 부른다. 레지스트리는 대리자 실행 스레드를 옮기지 않는다. `Changed` 는 내부 잠금 밖에서 발생하며 구독자 예외는 삼키지 않는다.
> 확장 규칙(UADR-0009): 앞으로의 기능(실행 가능 여부 변경 알림·토글 상태·비동기 실행·여러/화음 단축키)은 멤버 추가와 `UiCommandOptions` 속성 추가로만 연다. 기존 멤버의 서명·의미는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Add` | `Add(string! id, System.Action<UiCommandOptions!>! configure) -> bool` | 명령을 등록한다. |
| `CanExecute` | `CanExecute(string! id) -> bool` | 명령을 지금 실행할 수 있는지 확인한다. `CanExecute(string, object?)` 에 parameter=null 을 넘긴 것과 같다. |
| `CanExecute` | `CanExecute(string! id, object? parameter) -> bool` | 값을 넘겨 명령을 지금 실행할 수 있는지 확인한다. |
| `Changed` | `Changed -> System.EventHandler<UiRegistryChangedEventArgs!>?` | 명령이 등록·교체·제거되면 발생한다. `UiRegistryChangedEventArgs.Id` 는 명령 ID 다. |
| `Commands` | `Commands.get -> System.Collections.Generic.IReadOnlyList<UiCommandDefinition!>!` | 등록된 명령 전체의 사본. 등록 순서이며 교체는 자리를 유지한다(P3). |
| `Contains` | `Contains(string! id) -> bool` | 명령이 등록돼 있는지 확인한다. |
| `Execute` | `Execute(string! id) -> bool` | 명령을 실행한다. `Execute(string, object?)` 에 parameter=null 을 넘긴 것과 같다. |
| `Execute` | `Execute(string! id, object? parameter) -> bool` | 값을 넘겨 명령을 실행한다. |
| `Remove` | `Remove(string! id) -> bool` | 명령을 제거한다. |
| `TryGet` | `TryGet(string! id, out UiCommandDefinition? command) -> bool` | 명령 정의를 찾는다. |

## UiCommandOptions

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiCommandOptions`

`IUiCommandRegistry.Add(string, Action)` 의 구성 대리자가 채우는 명령 옵션이다.

> 모든 속성의 기본값은 null(또는 false)이다. 대리자가 끝난 시점의 값을 레지스트리가 복사해 두므로, 등록 뒤에 이 객체를 고쳐도 등록된 명령은 바뀌지 않는다. 바꾸려면 `Replace` 로 다시 등록한다. 확장 규칙(UADR-0009): 새 기능(예 토글 상태·비동기 실행·여러 단축키)은 기본값이 있는 속성을 추가하는 방식으로만 연다. 기존 속성의 의미·기본값은 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `CanExecute` | `CanExecute.get -> System.Func<UiCommandContext!, bool>?` | 실행 가능 여부 대리자. 기본값 null(항상 실행 가능). |
| `CanExecute` | `CanExecute.set -> void` | 실행 가능 여부 대리자. 기본값 null(항상 실행 가능). |
| `Category` | `Category.get -> string?` | 분류(예 "window"·"layout"). 기본값 null. |
| `Category` | `Category.set -> void` | 분류(예 "window"·"layout"). 기본값 null. |
| `DescriptionKey` | `DescriptionKey.get -> string?` | 설명 문구 키. 기본값 null. |
| `DescriptionKey` | `DescriptionKey.set -> void` | 설명 문구 키. 기본값 null. |
| `Execute` | `Execute.get -> System.Action<UiCommandContext!>?` | 실행 대리자. 기본값 null. |
| `Execute` | `Execute.set -> void` | 실행 대리자. 기본값 null. |
| `Gesture` | `Gesture.get -> string?` | 단축키. 기본값 null(단축키 없음). |
| `Gesture` | `Gesture.set -> void` | 단축키. 기본값 null(단축키 없음). |
| `Icon` | `Icon.get -> string?` | 아이콘 키(`IUiIconRegistry` 의 키). 기본값 null(아이콘 없음). |
| `Icon` | `Icon.set -> void` | 아이콘 키(`IUiIconRegistry` 의 키). 기본값 null(아이콘 없음). |
| `Replace` | `Replace.get -> bool` | 같은 ID 의 기존 명령을 교체할지 여부. 기본값 false. |
| `Replace` | `Replace.set -> void` | 같은 ID 의 기존 명령을 교체할지 여부. 기본값 false. |
| `Title` | `Title.get -> string?` | 제목. 기본값 null. 문구 키가 없을 때 그대로 표시한다. |
| `Title` | `Title.set -> void` | 제목. 기본값 null. 문구 키가 없을 때 그대로 표시한다. |
| `TitleKey` | `TitleKey.get -> string?` | 제목 문구 키. 기본값 null. 있으면 `Title` 보다 먼저 쓴다. |
| `TitleKey` | `TitleKey.set -> void` | 제목 문구 키. 기본값 null. 있으면 `Title` 보다 먼저 쓴다. |
| `UiCommandOptions` | `UiCommandOptions() -> void` | 기본값으로 옵션을 만든다. |

## UiCommandDefinition

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiCommandDefinition`

`IUiCommandRegistry` 에 등록된 명령 1건의 정의다. 등록 시점 옵션의 사본이며 바뀌지 않는다.

> 공개 생성자가 없다. 프레임워크(레지스트리)만 만든다. 확장 규칙: 새 정보는 읽기 전용 속성 추가로만 넓힌다. 기존 속성의 의미는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Category` | `Category.get -> string?` | 분류. 없으면 null. |
| `DescriptionKey` | `DescriptionKey.get -> string?` | 설명 문구 키. 없으면 null. |
| `Gesture` | `Gesture.get -> string?` | 단축키(별별UI 단축키 문법 — `UiCommandOptions.Gesture`). 없거나 검증에 실패했으면 null. |
| `Icon` | `Icon.get -> string?` | 아이콘 키(`IUiIconRegistry` 의 키). 없으면 null. |
| `Id` | `Id.get -> string!` | 명령 ID. |
| `Owner` | `Owner.get -> string!` | 등록 주체. 셸 기본 명령은 `UiRegistryOwners.Shell`, 모듈이 등록하면 모듈 ID, 실행 중 앱이 등록하면 `UiRegistryOwners.App`. |
| `Title` | `Title.get -> string?` | 제목(문구 키가 없을 때 그대로 표시). 없으면 null. |
| `TitleKey` | `TitleKey.get -> string?` | 제목 문구 키. 없으면 null. |

## UiCommandContext

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiCommandContext`

`UiCommandOptions.Execute`·`UiCommandOptions.CanExecute` 대리자가 받는 실행 문맥이다.

> 공개 생성자가 없다. 프레임워크(레지스트리)가 호출마다 만든다. 확장 규칙: 새 정보(예 호출 출처·취소 토큰)는 읽기 전용 속성 추가로만 넓힌다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `App` | `App.get -> IUiAppContext!` | 앱 컨텍스트. null 이 아니다. 셸이 아직 없으면 `IUiAppContext.Shell` 이 null 일 수 있다. |
| `CommandId` | `CommandId.get -> string!` | 실행하는 명령 ID. |
| `Parameter` | `Parameter.get -> object?` | 호출자가 `IUiCommandRegistry.Execute(string, object?)`·`IUiCommandRegistry.CanExecute(string, object?)` 로 넘긴 값. 1인자 오버로드로 부르면 null. |
