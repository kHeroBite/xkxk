## UiRegistryOwners

- 종류: `static class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiRegistryOwners`

아이콘·명령 레지스트리의 등록 주체(Owner) 이름과 프레임워크 예약 접두어를 모은다.

> 등록 주체는 `UiIconDefinition.Owner` 등에 남는 문자열이며 Ordinal(대소문자 구분)로 비교한다. 앱이 실행 중에 직접 등록하면 `App`, 모듈 컨텍스트로 등록하면 그 모듈 ID 가 주체가 된다.
> 예약 접두어(`ReservedPrefix`): 이 접두어로 시작하는 주체는 프레임워크 주체다. 프레임워크 아닌 주체는 아직 없는 `xkxk.` 명령 ID 를 새로 만들 수 없고(XKUI0308), `xkxk.` 아이콘 공급자 Id 를 등록할 수 없다(XKUI0206). 아이콘 키는 예약하지 않는다 — 명시 등록이 공급자 키를 가리는 것은 정상 재정의이고, 프레임워크는 아이콘을 명시 등록하지 않고 공급자로만 더하기 때문이다. 모듈 ID 의 `xkxk.` 접두어도 문서상 프레임워크 예약이지만 지금은 진단으로 검사하지 않는다.
> 확장 규칙: 상수는 추가만 한다(기존 값 변경·제거 금지).

| 상수 | 값 | 설명 |
|---|---|---|
| `App` | `app` | 앱이 실행 중 레지스트리(`IUiAppContext` 의 레지스트리)로 직접 등록할 때의 주체. |
| `Generated` | `xkxk.generated` | 프레임워크 생성 아이콘 공급자의 Id 이자 등록 주체. |
| `ReservedPrefix` | `xkxk.` | 프레임워크 예약 접두어(Ordinal, 대소문자 구분). |
| `Shell` | `xkxk.shell` | 셸 기본 명령의 등록 주체. |

## UiRegistryChangedEventArgs

|---|---|---|

| `Kind` | `Kind.get -> UiRegistryChangeKind` | 변경 종류. 모르는 값이면 전체가 바뀐 것으로 보고 다시 읽는다. |
