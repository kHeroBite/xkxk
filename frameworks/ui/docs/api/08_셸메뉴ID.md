# 08 셸메뉴ID — 공개 API 명세

## ShellMenuIds

- 종류: `static class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.ShellMenuIds`

프레임워크가 `IUiMenuRegistry` 에 기본으로 등록하는 셸 메뉴(파일·창·보기·시스템)의 ID 다.

> ID 규칙은 xkxk.\<루트\>.\<이름\> 이고 구분선은 xkxk.\<루트\>.sep\<n\> 이다. 모든 값은 예약 접두어 `UiRegistryOwners.ReservedPrefix` 로 시작한다. 소비자는 이 ID 를 Parent·InsertAfter·InsertBefore 앵커로 쓰거나 Move·SetHidden·Replace 로 바꿀 수 있다. 명령 ID(`ShellCommandIds`)와 같은 문자열이어도 레지스트리가 달라 충돌이 아니다. 확장 규칙: 새 셸 메뉴는 상수를 추가하고 표 끝 쪽에 덧붙인다. 기존 상수의 이름·값은 바꾸지 않는다.
