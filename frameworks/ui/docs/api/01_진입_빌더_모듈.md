## XkxkUi

- 종류: `static class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.XkxkUi`

별별UI 프레임워크의 공개 진입점이다. `XkxkUiBuilder` 는 이 형식의 `CreateBuilder` 로만 만든다.

> 확장 규칙(UADR-0009): 새 설정은 `XkxkUiBuilderOptions` 에 기본값 있는 속성으로만 추가한다. 기본값 파라미터(선택 파라미터)나 기존 서명 변경은 하지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `CreateBuilder` | `static CreateBuilder() -> XkxkUiBuilder!` | 기본 옵션(인자 없음·호스트 unknown·오류 정책 Collect)으로 빌더를 만든다. |
| `CreateBuilder` | `static CreateBuilder(string![]! args) -> XkxkUiBuilder!` | 명령줄 인자로 빌더를 만든다. 배열은 복사해 보관한다. |
| `CreateBuilder` | `static CreateBuilder(XkxkUiBuilderOptions! options) -> XkxkUiBuilder!` | 옵션 객체로 빌더를 만든다. 넘긴 인스턴스를 그대로 쓴다. |
| `Current` | `static Current.get -> IUiAppContext!` | 앱 컨텍스트(문구·화면 등록·메인 뷰모델·셸 명령). 항상 같은 비 null 인스턴스이며 대입할 수 없다(UADR-0011). |

## XkxkUiBuilder

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.XkxkUiBuilder`

별별UI 앱 구성 빌더. `XkxkUi.CreateBuilder()` 로만 만든다.

> 규칙 위반(빈 ID·중복 ID·구성 예외)은 진단으로 모은다. null 인자는 `ArgumentNullException` 이다. 확장 규칙(UADR-0009): 새 기능은 메서드 추가로만 넓히고 기존 서명은 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `AddModule` | `AddModule(UiModule! module) -> XkxkUiBuilder!` | 모듈을 등록한다. 구성은 `Build` 때 등록 순서대로 한다. |
| `AddModule` | `AddModule<TModule>() -> XkxkUiBuilder!` | 모듈 형식으로 등록한다(매개변수 없는 생성자로 만든다). |
| `Build` | `Build() -> XkxkUiApplication!` | 모듈을 등록 순서대로 1회씩 구성하고 앱을 만든다. 두 번째 호출은 `InvalidOperationException`. |
| `ConfigureServices` | `ConfigureServices(System.Action<UiServiceRegistry!>! configure) -> XkxkUiBuilder!` | 서비스 등록부를 구성한다. |
| `Diagnostics` | `Diagnostics.get -> UiDiagnostics!` | 진단 모음. |
| `Options` | `Options.get -> XkxkUiBuilderOptions!` | 빌더 옵션. |
| `Services` | `Services.get -> UiServiceRegistry!` | 서비스 등록부. |

## UiModule

> 확장 규칙(UADR-0009): 이 클래스에는 추상 멤버를 추가하지 않는다. 새 모듈 기능(예 의존 목록·순서·비동기 초기화)은 기본 구현이 있는 `virtual` 멤버로만 추가해 기존 파생 클래스의 소스·바이너리 호환을 지킨다.

| `Id` | `abstract Id.get -> string!` | 모듈 ID(Ordinal 비교). null·공백이면 XKUI0001 진단으로 건너뛴다. |

## IUiModule

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiModule`

별별UI 모듈의 최소 계약이다.

|---|---|---|
| `Configure` | `Configure(IUiModuleContext! context) -> void` | 모듈을 구성한다. `XkxkUiBuilder.Build` 가 등록 순서대로 1회 호출한다. |
| `Id` | `Id.get -> string!` | 모듈 ID(Ordinal 비교). null·공백이면 XKUI0001 진단으로 건너뛴다. |

## UiServiceRegistry

> 팩토리 등록은 첫 `Get`/`TryGet` 때 1회만 호출한다(스레드 안전). 리플렉션·동적 코드를 쓰지 않는다. 확장 규칙: 뒤 batch 의 키 조회·여러 개 등록은 새 메서드로 추가한다(기존 서명 불변).

## IUiServiceProvider

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiServiceProvider`

등록된 서비스를 형식으로 조회한다.

> 프레임워크만 구현한다. 소비자는 이 인터페이스를 구현하지 않는다. 확장 규칙: 뒤 batch 에서 여러 개 조회(GetAll)·키 조회 멤버를 추가할 예정이다(멤버 추가 허용).

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Contains` | `Contains<TService>() -> bool` | 서비스가 등록되어 있으면 true. |
| `Get` | `Get<TService>() -> TService!` | 서비스를 돌려준다. 없으면 `System.InvalidOperationException`. |
| `TryGet` | `TryGet<TService>(out TService! service) -> bool` | 서비스를 찾으면 true 와 인스턴스를 돌려준다. 팩토리 등록은 첫 조회 때 1회만 만든다. |
