## IUiWindowRegistry

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiWindowRegistry`

창 종류를 ID 로 등록·교체·제거·조회하고 여는 레지스트리다. 앱 전역은 `IUiAppContext.Windows`, 모듈 구성 중에는 `IUiModuleContext.Windows` 로 얻는다.

> 프레임워크만 구현한다. 소비자는 이 인터페이스를 구현하지 않는다. 앞으로 멤버가 추가될 수 있다.
> 등록 주체: 모듈 컨텍스트에서 얻은 레지스트리는 그 모듈 ID 를, 앱 컨텍스트에서 얻은 레지스트리는 `UiRegistryOwners.App` 를 등록 주체(`UiWindowDefinition.Owner`)로 기록한다. 셸은 창을 등록하지 않는다. 데모 창 3종(xkxk.demo.*)은 시험대 모듈이 같은 ID 로 등록한다(B10). 같은 저장소를 보므로 어느 쪽에서 등록해도 모두에게 보인다.
> ID 와 별칭: ID 는 Ordinal(대소문자 구분)로 비교한다. 별칭(`UiWindowOptions.Aliases`)은 대소문자를 무시하며 창을 찾을 때는 `TryResolve` 와 열기(`Open(string)`)만 본다. ID 와 별칭은 한 이름공간이라 새 ID 는 다른 창의 ID·별칭과 대소문자 무시로 겹칠 수 없다(XKUI0502).
> 예약 접두어: `UiRegistryOwners.ReservedPrefix`("xkxk.")로 시작하는 ID 와 별칭은 프레임워크가 쓴다. 프레임워크가 아닌 주체가 아직 없는 예약 ID 를 새로 만들면 등록하지 않고, 예약 별칭을 더하면 그 별칭만 버리고 등록한다 (둘 다 진단 XKUI0503). 이미 있는 예약 ID 를 `UiWindowOptions.Replace` 로 바꾸는 것(재정의)은 허용한다.
> 옛 이름·숫자: Grid·Gantt·Form(대소문자 무시)과 "0"·"1"·"2" 는 셸 기본 창 3종의 영구 예약어다. 셸(`UiRegistryOwners.Shell`) 밖의 등록은 이를 창 ID 로 쓸 수 없고(XKUI0502, 등록 안 함), 별칭으로 쓰면 그 별칭만 버린다(XKUI0503, 창은 등록).
> 등록·교체·제거 정책: Replace=true 인데 기존 창이 없으면 새로 등록한다(P1). 제거는 그 창을 등록한 주체만 할 수 있다(P2, 다른 주체면 XKUI0508). 교체는 주체와 무관하게 허용하며 `Items` 안의 자리를 유지한다(P3). 제거 뒤 다시 등록하면 맨 뒤에 붙는다. 빌드가 끝난 뒤 모듈이 붙잡아 둔 레지스트리로 등록하면 실행 중 등록과 같다(P4 — 즉시 검사, 진단은 `IUiAppContext.Diagnostics`, 예외 없음).
> 열린 문서: 교체·제거는 이미 열린 문서를 닫거나 바꾸지 않는다. 그 뒤의 새 열기와 레이아웃 복원부터 교체는 새 정의를, 제거는 자리표시(XKUI0505)를 쓴다.
> 규칙 위반은 예외 대신 진단(XKUI05xx)을 남기고 false 를 돌려준다. 다만 별칭만 버리는 위반은 창을 등록하고 true 다. 인자가 null 이면 `ArgumentNullException` 이다.
> 스레드: UI 스레드에서 부른다. 레지스트리는 대리자 실행 스레드를 옮기지 않는다. `Changed` 는 내부 잠금 밖에서 발생하며 구독자 예외는 삼키지 않는다.
> 확장 규칙(UADR-0009): 앞으로의 기능(예 강타입 등록·창 문맥)은 멤버 추가와 옵션 객체(`UiWindowOptions`·`UiWindowOpenOptions`) 속성 추가로만 연다. 기존 멤버의 서명·의미는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Add` | `Add(string! id, System.Action<UiWindowOptions!>! configure) -> bool` | 창 종류를 등록한다(또는 `UiWindowOptions.Replace`=true 로 교체한다). |
| `Changed` | `Changed -> System.EventHandler<UiRegistryChangedEventArgs!>?` | 창 종류가 등록·교체·제거되면 발생한다. `UiRegistryChangedEventArgs.Id` 는 창 ID 다. |
| `Contains` | `Contains(string! id) -> bool` | 창 종류가 등록돼 있는지 확인한다. |
| `Items` | `Items.get -> System.Collections.Generic.IReadOnlyList<UiWindowDefinition!>!` | 등록된 창 정의 전체의 사본. 등록 순서이며 교체는 자리를 유지한다(P3). |
| `Open` | `Open(string! id) -> bool` | 창을 정의의 기본값으로 연다. |
| `Open` | `Open(string! id, System.Action<UiWindowOpenOptions!>! configure) -> bool` | 열기 옵션을 정해 창을 연다. |
| `Remove` | `Remove(string! id) -> bool` | 창 종류를 제거한다. 그 창의 별칭도 함께 없어진다. 이미 열린 문서는 그대로 둔다. |
| `TryGet` | `TryGet(string! id, out UiWindowDefinition? window) -> bool` | ID 로 창 정의를 찾는다. 별칭은 보지 않는다. |
| `TryResolve` | `TryResolve(string! idOrAlias, out UiWindowDefinition? window) -> bool` | ID·별칭·옛 이름·숫자로 창 정의를 찾는다. ID(대소문자 구분) → 별칭(대소문자 무시) → 옛 이름·숫자 순서로 본다. |

## UiWindowOptions

- 종류: `sealed class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiWindowOptions`

`IUiWindowRegistry.Add(string, Action)` 의 구성 대리자가 채우는 창 종류 옵션이다.

> 기본값은 문자열·대리자가 null, `Placement` 가 `UiWindowPlacement.Default`, 참·거짓 속성이 false, `Aliases` 가 빈 목록이다. 대리자가 끝난 시점의 값을 레지스트리가 복사해 두므로, 등록 뒤에 이 객체를 고쳐도 등록된 창은 바뀌지 않는다. 바꾸려면 `Replace` 로 다시 등록한다. 확장 규칙(UADR-0009): 새 기능(예 기본 크기·열기 가능 조건)은 기본값이 있는 속성을 추가하는 방식으로만 연다. 기존 속성의 의미·기본값은 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |

| `Category` | `Category.set -> void` | 분류. 기본값 null. |

## UiWindowDefinition

> 공개 생성자가 없다. 프레임워크(레지스트리)만 만든다. 확장 규칙: 새 정보는 읽기 전용 속성 추가로만 넓힌다. 기존 속성의 의미는 바꾸지 않는다.

## UiWindowPlacement

- 종류: `enum` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiWindowPlacement`

창을 여는 배치 방식이다. 등록 값은 `UiWindowOptions.Placement`, 열 때 지정하는 값은 `UiWindowOpenOptions.Placement` 에 넣는다.

> 값이 추가될 수 있다. 모르는 값을 받으면 분리창(`Sdi`)이 아닌 것으로 보고 처리한다.
> 확장 규칙: 새 값은 끝에만 더하고 기존 값의 번호·의미는 바꾸지 않는다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Default` | `Default = 0 -> UiWindowPlacement` | 지정하지 않음. 등록 값이면 셸의 보통 문서 배치로 열고, 열기 옵션 값이면 창 정의의 배치(`UiWindowDefinition.Placement`)를 따른다. |
| `Sdi` | `Sdi = 1 -> UiWindowPlacement` | 분리창(SDI)으로 연다. |

## IUiWindowContext

- 종류: `interface` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.IUiWindowContext`

열린 창(문서) 하나의 문맥이다. 뷰모델은 `UiWindowViewModel.Window` 로 이 문맥을 받아 자기 창의 제목을 바꾸고, 창을 닫고, 바쁨 표시를 켠다.

> 프레임워크만 구현한다. 소비자는 구현하지 않는다(시험용 가짜 구현은 예외). 확장 규칙: 새 기능은 멤버 추가로만 넓힌다. 기존 멤버의 서명·의미는 바꾸지 않는다. 창이 닫힌 뒤에는 `SetTitle`·`Close` 가 `false` 를 돌려주고, `BeginBusy()` 는 아무 일도 하지 않는 `IDisposable` 을 돌려준다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `BeginBusy` | `BeginBusy() -> System.IDisposable!` | 바쁨 표시를 켠다. 돌려받은 값을 해제하면 꺼진다. 여러 번 겹쳐 켤 수 있다. |
| `BeginBusy` | `BeginBusy(string! reason) -> System.IDisposable!` | 사유를 붙여 바쁨 표시를 켠다. 돌려받은 값을 해제하면 꺼진다. |
| `Close` | `Close() -> bool` | 이 창을 닫는다. |
| `Closed` | `Closed -> System.EventHandler?` | 창이 닫힌 뒤 한 번 발생한다. |
| `DocumentId` | `DocumentId.get -> string!` | 이 창을 담은 문서의 ID. 같은 창을 여러 개 열면 문서마다 다르다. |
| `IsOpen` | `IsOpen.get -> bool` | 창이 아직 열려 있으면 `true`. 닫힌 뒤에는 `false`. |
| `Parameter` | `Parameter.get -> object?` | 창을 열 때 넘긴 값. 없으면 `null`. |
| `SetTitle` | `SetTitle(string! title) -> bool` | 문서 제목을 바꾼다. |
| `Title` | `Title.get -> string!` | 현재 문서 제목. |
| `WindowId` | `WindowId.get -> string!` | 창 ID(`UiWindowDefinition.Id`). 별칭으로 열었어도 등록된 ID 다. |

## UiWindowViewModel

- 종류: `abstract class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiWindowViewModel`

창 내용의 뷰모델 기반 형식이다. 프레임워크가 창을 열 때 만들어 `Window` 에 창 문맥을 연결하고, 열린 뒤 `OnOpenedAsync`, 닫힌 뒤 `OnClosed` 를 한 번씩 부른다.

> 파생 형식은 매개변수 없는 protected 생성자를 쓴다. 열 때 넘긴 값의 형식을 강제하려면 `UiWindowViewModel` 를 상속한다. `AttachWindow`·`NotifyOpenedAsync`·`NotifyClosed` 는 프레임워크 전용 공개 진입점이다. 소비자 코드는 부르지 않는다(편집기 자동 완성에서 숨김).

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `AttachWindow` | `AttachWindow(IUiWindowContext! window, object? parameter) -> void` | 창 문맥과 열 때 넘긴 값을 연결한다(프레임워크 전용). |
| `NotifyClosed` | `NotifyClosed() -> void` | 창이 닫혔음을 알린다(프레임워크 전용). 첫 호출만 `OnClosed` 를 부른다. |
| `NotifyOpenedAsync` | `NotifyOpenedAsync(System.Threading.CancellationToken cancellationToken) -> System.Threading.Tasks.Task!` | 창이 열렸음을 알린다(프레임워크 전용). 첫 호출만 `OnOpenedAsync` 를 부르고 이후는 바로 끝난다. |
| `Parameter` | `Parameter.get -> object?` | 창을 열 때 넘긴 값. 없거나 연결 전이면 `null`. |
| `PropertyChanged` | `PropertyChanged -> System.ComponentModel.PropertyChangedEventHandler?` | 속성 값이 바뀌면 발생한다. |
| `UiWindowViewModel` | `UiWindowViewModel() -> void` | 뷰모델을 만든다. 창 문맥은 프레임워크가 나중에 연결한다. |
| `Window` | `Window.get -> IUiWindowContext!` | 이 뷰모델이 담긴 창의 문맥. |
| `AcceptParameter` | `virtual AcceptParameter(object? parameter) -> bool` | 열 때 넘긴 값을 이 뷰모델이 받을 수 있는지 판정한다. |
| `OnOpenedAsync` | `virtual OnOpenedAsync(System.Threading.CancellationToken cancellationToken) -> System.Threading.Tasks.Task!` | 창이 열린 뒤 한 번 불린다. 자료 읽기 등 비동기 초기화를 여기서 한다. |
| `OnClosed` | `virtual OnClosed() -> void` | 창이 닫힌 뒤 한 번 불린다. 구독 해제 등 정리를 여기서 한다. 기본 구현은 아무 일도 하지 않는다. |
| `OnPropertyChanged` | `OnPropertyChanged(string! propertyName) -> void` | `PropertyChanged` 를 발생시킨다. |
| `SetProperty` | `SetProperty<T>(ref T field, T value, string! propertyName) -> bool` | 필드 값이 다르면 바꾸고 `PropertyChanged` 를 발생시킨다. |

## UiWindowViewModel\<TArgs\>

- 종류: `abstract class` · 전체 이름: `xkxk.frameworks.ui.shell.Framework.UiWindowViewModel<TArgs>`

열 때 넘긴 값을 `TArgs` 로 받는 창 뷰모델 기반 형식이다.

> 값이 없으면(`null`) `Args` 는 기본값이다. `TArgs` 가 아닌 값을 넘기면 연결되지 않고 프레임워크가 XKUI0509 진단을 남긴다.

| 멤버 | 시그니처 | 설명 |
|---|---|---|
| `Args` | `Args.get -> TArgs?` | 열 때 넘긴 값. 없거나 연결 전이면 기본값. |
| `UiWindowViewModel` | `UiWindowViewModel() -> void` | 뷰모델을 만든다. 창 문맥과 값은 프레임워크가 나중에 연결한다. |
| `AcceptParameter` | `override AcceptParameter(object? parameter) -> bool` | 값이 `null` 이거나 `TArgs` 면 받는다. |

## UiWindowViewRegistration

- 종류: `static class` · 전체 이름: `xkxk.frameworks.ui.views.Windows.UiWindowViewRegistration`

창 한 종류를 뷰모델과 뷰 형식으로 등록하는 확장 메서드다(부록 a11 §4).

> 모든 오버로드는 `IUiWindowRegistry.Add(string, Action)` 위에 얹고 `UiWindowOptions.CreateContent` 를 채운다. 구성 대리자가 `UiWindowOptions.CreateContent` 를 설정해도 이 등록이 덮어쓴다(진단 없음). 반환값은 `Add` 결과다.
> 내용을 만들 때의 흐름: 뷰모델 생성 → 창 문맥·파라미터 연결(형식이 맞지 않으면 XKUI0509 와 자리표시) → `new TView { DataContext = 뷰모델 }` → 뷰가 처음 시각 트리에 붙을 때 `OnOpenedAsync` 1회(예외는 XKUI0510, 뷰 유지) → 창이 닫힐 때 토큰 취소와 `OnClosed` 1회. 생성 함수가 null 을 돌려주거나 예외를 던지면 XKUI0507 과 자리표시다.
> 선택 파라미터는 쓰지 않는다(UADR-0009). 인자가 null 이면 `ArgumentNullException` 이다.

|---|---|---|
| `Register` | `Register<TViewModel, TView>(this IUiWindowRegistry registry, string id) -> bool` | 뷰모델을 `new()` 로 만드는 창을 기본 옵션으로 등록한다. 제약: `TViewModel : UiWindowViewModel, new()`, `TView : Control, new()`. |
| `Register` | `Register<TViewModel, TView>(this IUiWindowRegistry registry, string id, Action<UiWindowOptions> configure) -> bool` | 뷰모델을 `new()` 로 만드는 창을 구성 대리자로 등록한다. 제약: `TViewModel : UiWindowViewModel, new()`, `TView : Control, new()`. |
| `Register` | `Register<TViewModel, TView>(this IUiWindowRegistry registry, string id, Action<UiWindowOptions> configure, Func<UiWindowContentContext, TViewModel> createViewModel) -> bool` | 뷰모델 생성 함수를 받아 창을 등록한다. 제약: `TViewModel : UiWindowViewModel`, `TView : Control, new()`. |
| `Register` | `Register<TViewModel, TView, TArgs>(this IUiWindowRegistry registry, string id) -> bool` | 열 때 `TArgs` 를 받는 창(뷰모델 `new()`)을 기본 옵션으로 등록한다. 제약: `TViewModel : UiWindowViewModel<TArgs>, new()`, `TView : Control, new()`. |
| `Register` | `Register<TViewModel, TView, TArgs>(this IUiWindowRegistry registry, string id, Action<UiWindowOptions> configure) -> bool` | 열 때 `TArgs` 를 받는 창(뷰모델 `new()`)을 구성 대리자로 등록한다. 제약: `TViewModel : UiWindowViewModel<TArgs>, new()`, `TView : Control, new()`. |
| `Register` | `Register<TViewModel, TView, TArgs>(this IUiWindowRegistry registry, string id, Action<UiWindowOptions> configure, Func<UiWindowContentContext, TViewModel> createViewModel) -> bool` | 열 때 `TArgs` 를 받는 창을 뷰모델 생성 함수로 등록한다. 제약: `TViewModel : UiWindowViewModel<TArgs>`, `TView : Control, new()`. |
