# 별별UI 소비자 문서

- 상태: 사전판(0.x 이전). 공개 API 는 전부 미출시(Unshipped) 표면이라 다음 판에서 바뀔 수 있다.
- 최종 갱신일: 2026-11-27
- 대상: 별별UI(XKXK 제품군 공용 UI 프레임워크, Avalonia 기반)를 자기 솔루션에 넣어 쓰는 개발자와 그 솔루션에서 일하는 AI 에이전트.

## 공개 범위

- 공개 계약은 네임스페이스 `xkxk.frameworks.ui.shell.Framework` 의 형식 중 공개 API 목록 파일(`PublicAPI.Unshipped.txt`·`PublicAPI.Shipped.txt`)에 실린 것뿐이다. 명세 [api/README.md](api/README.md) 에 나오는 형식이 그 전부다.
- 같은 어셈블리의 다른 public 형식(예 셸 내부 뷰모델·도킹·테마 형식)은 공개 계약이 아니다. 컴파일은 되더라도 예고 없이 바뀌거나 사라질 수 있으므로 쓰지 않는다.
- 공개 계약 형식의 속성이 공개 계약이 아닌 형식을 돌려주는 경우가 있다(예 `IUiAppContext.Settings`·`IUiAppContext.Themes`). 그 반환 형식의 멤버도 계약이 아니다.

## 현재 상태

- 판: 사전판(0.x 이전). 출시(Shipped) 표면은 아직 없다. 미출시 표면은 바뀔 수 있지만, 별별UI 는 공개 API 를 바꿀 때 **추가만** 하는 원칙(아래 호환 규칙)을 지금부터 지킨다.
- 공개 표면은 지금 셸 층(`xkxk.frameworks.ui.shell`) 한 곳이다. 다른 층(`xkxk.frameworks.ui`·`xkxk.frameworks.ui.data`·`xkxk.frameworks.ui.views`)은 아직 공개 계약 대상이 아니다.
- 대상 런타임은 .NET 11(`net11.0`), UI 는 Avalonia 12.1.4·Dock.Avalonia 12.1 이다. 호스트는 데스크톱·브라우저(WebAssembly)·Android 세 가지가 있다.

## 얻는 방법

- **지금**: XKXK 모노레포를 받아 `frameworks/ui/src/xkxk.frameworks.ui.shell/xkxk.frameworks.ui.shell.csproj` 를 자기 프로젝트에서 ProjectReference 로 참조한다. 자세한 절차는 [01_시작하기.md](01_시작하기.md) 에 있다.
- **예정**: NuGet 패키지 게시는 앞으로의 배포 단계에서 한다. 게시되면 PackageReference 로 바꾸며, 패키지 안에 이 `docs/` 폴더도 함께 넣을 예정이다. 게시 전까지는 저장소 경로가 유일한 입수 경로다.

## 호환 규칙 요약

- 공개 API 는 지우지 않고, 서명을 바꾸지 않고, 의미를 바꾸지 않는다. 새 기능은 멤버·옵션 속성·열거형 값을 **더하는 것**으로만 연다.
- 새 설정은 메서드 매개변수가 아니라 옵션 객체(예 `XkxkUiBuilderOptions`·`UiCommandOptions`·`UiMenuItemOptions`)의 기본값 있는 속성으로 들어온다. 그래서 소비자는 옵션 람다로 필요한 값만 채우면 다음 판에서도 그대로 컴파일된다.
- 소비자가 구현하라고 연 확장점은 추상 클래스 두 개(`UiModule`·`UiIconProvider`)뿐이다. 인터페이스(`IUiAppContext`·`IUiModuleContext`·레지스트리 인터페이스 등)는 프레임워크만 구현하며, 소비자가 구현하면 멤버가 늘어나는 다음 판에서 깨진다.
- 저장소 공통 원칙 원문은 [저장소 공개 API 호환 원칙](../../../docs/standards/02_공개API_호환원칙.md) 이다(저장소 안에서만 열린다).

## 갱신 규칙

- `api/` 아래 파일은 생성물이다. 손으로 고치지 않는다. 별별UI 저장소에서 `python3 -B tools/gen_api_docs.py` 로 다시 만든다.
- 이 폴더의 수기 문서(README·01·02·03·04)는 공개 API 가 바뀌는 작업에서 함께 고친다. 별별UI 저장소의 검사기(`bash test/framework/verify_framework.sh --stage docs`)가 문서에 적힌 공개 형식·멤버·진단 코드·ID 를 실제 공개 표면과 대조해 낡은 이름을 잡는다.
- 쓰는 쪽에서 문서와 실제 동작이 다른 것을 발견하면 별별UI 저장소 관리자에게 알린다. 쓰는 쪽에서 이 폴더를 고치지 않는다.
