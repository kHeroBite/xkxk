> 이 폴더는 ref_root 다. 벤치마킹·레퍼런스 대상의 색인과 분석 메모만 둔다. 받은 원본은 저장소 밖에 두고, 코드는 복제하지 않는다.
> 규약은 하네스 ocanon 스킬을 따른다. 참조한 곳에는 `ref:<id>@<커밋 12자>:<경로>` 표기를 남긴다.
