## 1. 무엇을 적었나

- 새 홈 `/mnt/c/DATA/Project/xkxk/frameworks/ui` 의 `test`·`tools` 아래 py·sh·ps1·mjs·js·json 파일 중 `poc/ui` 문자열 또는 절대경로 `/mnt/c/DATA/Project/Pd`(대소문자 무관)를 가진 파일 전부다. bin·obj·logs·`__pycache__` 는 뺐다.
- 종류는 이렇게 나눴다.
  - 상대 = 저장소 상대 경로 `poc/ui/...` 를 쓴다. 새 홈에서는 앞의 `poc/ui/` 를 떼야 한다(영역 루트 기준).
  - 절대 = `/mnt/c/DATA/Project/Pd/...` 절대경로를 쓴다. 새 홈 경로나 스크립트 위치 기준 경로로 바꿔야 한다.
  - 주석만 = 해당 문자열이 주석 줄에만 있다. 동작에는 영향이 없다.
- 해당 줄 수는 문자열을 가진 줄의 개수다. 주석·사용 안내 줄도 셌으므로 "상대"로 분류됐어도 실제 동작 줄은 더 적을 수 있다.
- 스캔 명령은 세션 임시 스크립트(이번 사이클 뒤 삭제)였다. 다시 셀 때는 아래 셸 한 줄로 같은 결과를 얻는다.

```bash
cd /mnt/c/DATA/Project/xkxk/frameworks/ui && grep -rlE --include='*.py' --include='*.sh' --include='*.ps1' --include='*.mjs' --include='*.js' --include='*.json' --exclude-dir=bin --exclude-dir=obj --exclude-dir=logs --exclude-dir=__pycache__ 'poc/ui|/mnt/c/DATA/Project/[Pp]d\b' test tools | sort
```

## 2. 이번 사이클에 이미 고친 도구(참고)

- `tools/check_layers.py`·`tools/check_layers_rules.json`·`tools/classify_layers.py`·`plan/_build/menu_icons.py` 는 동작 경로를 영역 루트 기준으로 고쳤다. 원본과 같은 계층 검사 결과(layers·files·violations)가 나오는 것을 확인했다.
- 이 도구들에 남은 `poc/ui` 는 사용 안내 주석과 `classify_layers.py` 의 생성 문구(`# poc/ui 소스 계층 분류표` 등)뿐이다. 생성 문구를 바꾸면 `LAYERS.md` 대조 결과가 원본과 달라지므로 일부러 두었다. 아래 표에 "상대"로 나오는 것은 이 주석·생성 문구 때문이다.
- `tools/classify_layers_overrides.json` 은 `_note` 설명 문자열에만 `poc/ui/src/` 가 있다.

## 3. 고치지 않은 것 — 핵심 항목(고치기 전 상태 기록, 처리는 §5)

- `tools/partial_gate.py` 의 `DEFAULT_SRC = "/mnt/c/DATA/Project/pd/poc/ui/src"` 절대경로는 고치지 않았다(TODO, UTODO-0001). 새 홈에서 쓰려면 `--src` 를 주거나 기본값을 스크립트 위치 기준 `../src` 로 바꿔야 한다.

- `tools/partial_gate.py` 의 `DEFAULT_SRC` 는 스크립트 위치 기준 `../src`(영역 루트의 src)로 바꿨다. `tools/classify_layers.py` 의 생성 문구(`# poc/ui 소스 계층 분류표`)도 `# frameworks/ui 소스 계층 분류표` 로 바꿨고 `LAYERS.md` 를 재생성해 `classify_layers.py --check` rc=0 을 확인했다(§2 의 "일부러 두었다" 는 이 처리로 끝났다).
