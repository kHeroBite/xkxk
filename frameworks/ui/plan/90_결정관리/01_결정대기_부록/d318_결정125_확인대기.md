# 부록 — D-318~328 결정 125 판단(권장안 적용 11)

> `../01_결정대기_질문목록.md` 의 부록이다. 직전 부록은 같은 폴더의 `d306_결정124_확인대기.md`(D-306~D-317, 확인 대기 12)다.
> 2026-11-14 사용자가 새 요구 2건을 냈다. GPU 를 쓸 수 없는 PC·원격 환경에서도 문제없이 쓰도록 GPU 모드를 끄는 길(기동 파라미터·메인 프로그램 on/off·메뉴가 안 보일 때 단축키)과, 개인 전용 무료 플래너 프로그램을 같은 구조로 만들어 Pd 무료 계정 → 유료 계정 전환을 유도하는 구조다(결정 125, 근거 `../02_결정기록_부록/b31_ADR-109.md`, 요구 REQ-93·REQ-94). 이 부록은 그 정책을 구현할 때 사용자 원문만으로 정해지지 않는 판단 11건을 적는다.
> 11행 모두 옵션화 대원칙(ADR-089)과 결정 124 횡단 원칙(모든 값 옵션화, 예외는 법령·보안·무결성)으로 판단한 권장안을 문서에 먼저 적용했고 상태는 **확인 대기**다. 사용자가 다른 선택지를 고르면 상태를 **변경 확정**으로 바꾸고 바뀐 내용을 잠정안 칸 끝 문장에 적는다. 권장안 그대로면 **확정**으로 바꾼다.
> 결과(2026-11-14, 결정 126 — 근거 `../02_결정기록_부록/b32_ADR-110.md`): 사용자 확인으로 11행이 확정 9·변경 확정 2 가 됐다. D-323 은 이름이 `**planer`(가칭)·별별플래너로, D-327 은 유틸 위젯·새 창 두 형태와 서브 ID `PLT-09-U1` 로 바뀌었고 바뀐 내용은 각 행 잠정안 칸 끝 괄호에 적었다. 새 판단 D-329~D-332 는 `d329_결정126_확인대기.md` 에 있고 다음 D 번호는 D-333 이다.
> 값은 확정값이 아니라 초기 제시값이고, 행마다 설정 주체(사용자 옵션, 회사 담당자 옵션 또는 pd-admin 제품 옵션)를 같은 문장에 적었다. 설정 키 이름은 전부 후보다(클라이언트 settings.json 키는 `GpuMode`·`GpuHotkey`·`GpuRemoteAutoOff`·`GpuStartMarker`, 점 표기는 서버·회사 옵션 이름 후보). 고정(옵션 아님)은 법령·보안·무결성 예외뿐이며 같은 행에 근거를 적었다. 새 결정 번호는 결정 125 하나이고 D 행은 그 하위 판단이다. 다음 D 번호는 D-329 이다.
> 적용 위치는 절 이름으로 적었다.
