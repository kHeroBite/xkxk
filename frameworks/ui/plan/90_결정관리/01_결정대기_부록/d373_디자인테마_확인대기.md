# 부록 — D-373~384 결정 134 판단(권장안 적용 12)

> `../01_결정대기_질문목록.md` 의 부록이다. 2026-11-16 사용자가 색 테마와 별개로 아기자기·심플·화려·3D 효과 같은 '디자인 테마'를 고객이 고르게 하고, 여러 분야 앱을 참조하라고 요구했다(결정 134, REQ-104, 근거 `../02_결정기록_부록/b40_ADR-118.md`, 설계 정본 `../../09_화면설계/18_디자인테마_설계.md`, 조사 `../../01_시장조사/19_디자인테마_앱레퍼런스_조사.md`). 이 부록은 사용자 원문만으로 정해지지 않는 판단 12건을 적는다.
> 12행 모두 옵션화 대원칙(ADR-089)과 하드코딩 금지 대원칙(REQ-99)으로 판단한 권장안을 문서에 먼저 적용했다. 상태는 모두 **권장안 먼저 적용, 사용자 확인 대기** 이다. 값(범위·기본값·수치)은 확정값이 아니라 초기 제시값이고 설정 키 이름은 후보다.
> 기술 타당성 판정은 Avalonia 12.1.4 공식 문서 기준이다. 진짜 3D 공간 창 관리는 공식 미지원이라 불가능으로 판정했고(D-376), 대안 4종만 구현한다. 다음 D 번호는 D-385 이다.
