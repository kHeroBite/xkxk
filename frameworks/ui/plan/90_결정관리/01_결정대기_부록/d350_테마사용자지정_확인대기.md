# 부록 — D-350~355 결정 131 판단

> 상태 대장(결정 142) · 행 상태의 정본은 표의 상태 칸이다(D-498). 다른 칸은 결정 당시 서술이라 고치지 않는다(`../../05_아키텍처/53_Pd_용어_상태어휘_문서규칙.md` §3.2).
> `../01_결정대기_질문목록.md` 의 부록이다. 2026-11-15 사용자가 "기본 테마(템플릿)을 선택후 각 요소마다 색상이나 폰트나 글자크기나 디자인항목들을 사용자가 커스터마이징 가능해야 한다." 라고 요구했다(결정 131, REQ-101, 근거 `../02_결정기록_부록/b37_ADR-115.md`, 설계 정본 `../../09_화면설계/17_테마_요소별_사용자지정_설계.md`). 이 부록은 사용자 원문만으로 정해지지 않는 판단 6건을 적는다.
> 6행 모두 옵션화 대원칙(ADR-089)과 하드코딩 금지 대원칙(REQ-99)으로 판단한 권장안을 문서에 먼저 적용했다. 값(범위·기본값)은 기본값(후보)이고 설정 키 이름은 후보다.
