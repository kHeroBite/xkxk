# ADR-115 테마 템플릿 선택 뒤 요소별 사용자 지정 (결정 131, 2026-11-15)
> 작성일 2026-11-15 · 상태 **확정 전**(방향은 사용자 요구로 확정, 세부 D-350~D-355 는 권장안 먼저 적용·사용자 확인 대기)
> 사용자 요구 원문 정본은 `../../00_요구사항/01a_사용자요구사항_원문_2.md` §3-0m 이다. 설계 정본은 `../../09_화면설계/17_테마_요소별_사용자지정_설계.md` 이고 이 부록은 결정과 근거만 적는다. 값은 REQ-99 에 따라 기본값·설정 주체를 같이 읽는다.

## ADR-115. 결정 131 (2026-11-15)

### 1. 맥락

- 사용자가 "기본 테마(템플릿)을 선택후 각 요소마다 색상이나 폰트나 글자크기나 디자인항목들을 사용자가 커스터마이징 가능해야 한다." 라고 요구했다(REQ-101).
- 현재는 내장 템플릿 7종 선택, 사용자 테마 복제·토큰 색 편집·내보내기·가져오기, 전역 글꼴·크기(문서·시스템 두 범위)만 있다. 요소 단위 글꼴·크기·굵기·모서리·테두리·여백과 템플릿 값으로 되돌리기는 없다. 사용자 테마는 색 전체 사본이라 원본 템플릿을 모른다.
- 회사 계층(REQ-100)의 테마 정책은 다른 세션이 설계 중이다. 이번 범위는 사용자 계층이며, 서버 저장·회사 정책 강제는 설계만 한다(PoC 에 서버 사용자 설정 저장소와 회사 정책 배포 경로가 아직 없다).

### 3. 대안

| 안 | 내용 | 판정 |
|---|---|---|
| A(채택) | 요소 카탈로그 + 요소별 설계 리소스 키 + 앱 수준 스타일 1장, 사용자 덮어쓰기만 희소 저장 | 실현 4·가치 5·위험 2. 요소 단위 요구를 충족하고 Fluent 버전 의존이 낮다 |
| B | 요소마다 Avalonia ControlTheme 을 사용자 값으로 런타임 생성 | 테마 템플릿 전체 재생성이라 MDI 크롬·DataGrid 테마와 충돌 위험이 크다 |
| C | Fluent 전역 리소스(`ControlCornerRadius` 등)만 바꾸는 전역 조정 | '요소마다' 요구를 충족하지 못한다 |

저장 방식은 전체 값 기록 대신 희소 저장을 택했다. 바꾸지 않은 키는 저장되지 않아 새 기본값이 저장 프로필에 전파되지 않는 문제가 이 기능에서는 생기지 않는다. 기존 설정 전체의 값 기록 방식은 이번 범위 밖이라 TODO-171 로 남긴다.

### 4. 결과

- 좋은 점은 이렇다. 요소 단위 변경이 즉시 반영되고 속성·요소·전체 단위로 템플릿 값에 되돌릴 수 있다. 옛 저장본과 기존 테마가 깨지지 않는다(Design 빈 사전). 회사 정책(REQ-100)이 나중에 잠금 목록만 공급하면 붙는다.
- 비용은 테마 모델 확장(Design 사전·기반 템플릿 Id)과 요소별 스타일 1장, 편집 화면 영역 1개다.
- 위험은 Avalonia 의 로컬 값 우선순위 때문에 일부 대상에서 요소 지정이 먹지 않을 수 있다는 점이다(확실하지 않음, 구현 때 대상별 실측으로 확인해 안 되는 대상은 설계 문서에 '해당 없음 + 근거' 로 적는다).
- 이월은 TODO-170(서버 사용자 설정 저장 연결), TODO-171(설정 전체 값 기록 → 희소 저장 검토), TODO-172(회사 잠금 연결, REQ-100 문서 확정 뒤)이다.

### 5. 재검토 조건

- REQ-100 문서가 회사 값·잠금 형식을 다르게 정하면 131-3 의 접점을 맞춘다.
- 사용자가 D-350~D-355 중 하나라도 다르게 답하면 그 D 행만 바꾼다(결정 번호 변경 없음).
- 요소 목록에 추가 요구가 생기면 설정 표에 행만 더한다.
- 로컬 값 우선순위로 지정이 먹지 않는 대상이 많으면 안 B 를 부분 재검토한다.

### 6. 옵션

| 항목 | 기본값 | 설정 주체 | 비고 |
|---|---|---|---|
| 요소별 속성 값 | 현재 화면과 같은 제품 기본값(오프셋 0 등) | 사용자 | 설정 키 `theme.design.<요소>.<속성>` |
| 값 범위 | 크기 오프셋 −4~+8, 모서리 0~16, 테두리 0~4, 여백 0~24 | 제품 설정 표 | 초기 제시값 |
| 대비 경고 기준 | 4.5:1·3:1·대비 테마 7:1 | 제품 설정 표 | 초기 제시값, 경고 표시는 끌 수 없음 |
| 잠금 목록 | 빈 값 | 회사 담당자(REQ-100) | PoC 는 공급자 없음 |

### 7. 관련 결정과의 관계

- ADR-089(옵션화 대원칙)·ADR-112(REQ-99)의 값은 설정 키 + 기본값 규칙을 따른다.
- 기존 테마 규칙(`../../09_화면설계/01_화면설계_공통원칙.md` §5.1)을 바꾸지 않고 요소 단위를 더한다.
- 창 크롬 수치는 `../../04_기술스택/05_창크롬_OS디자인_기준.md` 를 그대로 따른다.
- REQ-100(다른 세션)과는 실효값 합성 순서와 잠금 접점으로만 맞닿는다.
