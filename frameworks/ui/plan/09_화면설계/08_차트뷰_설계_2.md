# 차트뷰 설계 2 — 뷰 등록부

> 상태 설계 정본(ADR-076). `08_차트뷰_설계.md` §2 의 등록 규격으로 모은 뷰 등록부다.
> 뷰의 정의 자리는 소유 모듈 선언서의 '화면과 메뉴' 항목이다(`../05_아키텍처/32_Pd_모듈화_조립구조_설계.md` §3.1·§7, D-509). 이 표는 선언에서 모은 파생 표이고, 선언을 모으는 생성기가 생기기 전까지 손으로 맞춘다. 선언과 이 표가 다르면 선언이 정본이다.
> 뷰 단위 단계는 이 표의 '단계' 칸이 정본이다. WBS 행은 이 칸을 가리킨다. 화면 노출 값(○·△·✕)은 메뉴 생성기 데이터 `../_build/menu_data.py` 가 정본이고, 이 표의 '스마트폰' 칸은 그 화면 값을 넘지 않는 뷰 값이다.

## 1. 칸의 뜻

| 칸 | 뜻 |
|---|---|
| CV | 뷰 번호. 불변이고 지운 번호를 다시 쓰지 않는다(`../05_아키텍처/53_Pd_용어_상태어휘_문서규칙_2.md` §5 의 CV 접두). |
| 소유 모듈 | 뷰를 선언하는 모듈. 이 모듈이 테넌트 허용에 없으면 뷰가 없다. |
| 귀속 기능·화면 | 뷰가 확장하는 기능 ID 와 뷰를 여는 화면 ID. |
| 그리기 | 공통 차트(`ChartSpec`)·공통 보드(보드 플러그인)·시간축(시간축 렌더러 플러그인)·직접 그리기·그래프 레이아웃·캘린더 격자·컨테이너 가운데 하나. 규칙은 08 §3.11. '미판정'은 PoC 뒤 정한다. |
| 데이터 원천 | 뷰가 읽는 모듈. 분석 차트는 `rpt` 지표(`rpt.q.metric_value`)로 읽고 원천 모듈은 지표 원천 포트(`rpt.port.metric_source`)를 구현한다(D-504). 원천 일부가 허용에 없을 때 동작은 08 §3.9 다. |
| 스마트폰·태블릿·PC형·웹 | 폼팩터별 뷰 값. 카드 문서 표기는 카드의 폼팩터 줄을 따른다는 뜻이다. |
| 단계 | 뷰를 여는 단계(M1~M4·X). 귀속 기능의 단계와 다를 수 있다. 보류는 결정 번호와 함께 적는다. |
