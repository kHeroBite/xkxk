## 0. 요약

- 검토 판정이 흡수·변형 흡수인 행 중 새 패턴 성격인 것을 66개 패턴(UX-29~UX-94)으로 묶었다. 여러 임시 행이 한 패턴으로 합쳐진 경우가 있다.
- OSS 소스 열람 메모(`ref/analysis/` 의 files·vscode·affine·excalidraw·logseq·joplin·plane·openproject·taiga·zulip·mattermost·thunderbird)에서 18a~18d 에 없던 패턴 19개를 UX-95~UX-113 으로 더했다(§2.8). 모두 후보이며 코드는 가져오지 않는다.
- 기존 패턴을 넓히는 행(UX-05·14·18·19·22·24 보강)은 새 번호를 주지 않았다(13a §2).
- 새 기능을 만들지 않고 기존 기능 확장으로 담는 것이 기본이다. 신규 기능(BX) 여부는 18 총괄이 판정한다. 이 문서의 '흡수 대상' 칸은 현행 기능 ID 를 적는다.
- 차트뷰 번호는 CV-40 지식 그래프(소속 KMS-04)와 CV-41 화이트보드 캔버스(소속 COL-17)다(§5).
- 신규 기능 번호는 18 총괄이 정했다. 설계 등재한 기능은 KMS-04 객체 간 연결 패널·COL-17 회고·브레인스토밍 보드다. BX-01 예약 페이지는 새 기능 ID 없이 COL-13 확장으로 흡수했고(M4, D-250), BX-02 데스크톱 전역 빠른 캡처는 PLT-11(M4)로 설계 등재했으며(D-253), BX-03 비동기 화면 녹화 보고는 등재하지 않고 출시 뒤 X 후보로 둔다(D-252).
- 화면 공통 UX 규칙 다섯은 §3 이 유일한 정본이다.

## 1. 표기·기존 결정과의 관계

- 폼팩터 칸은 UI 모드 MDI·DOCK·NAV 로 쓴다. 스마트폰은 NAV 만 쓴다(`plan/05_아키텍처/08_지원_폼팩터_용어.md` §8).
- '옵션화' 칸은 기본 동작과 그 값을 바꾸는 설정 층(회사 층·하위 범위 층·사용자 층, 53 §1.4)을 적는다(옵션화 대원칙 ADR-089). 설정 키는 패턴을 구현하는 기능의 소유 모듈이 10 문서 설정 키 절에 선언한다. 이 칸은 키가 이미 있으면 키 이름만 적고 값을 다시 적지 않는다. 값 분류가 기본값이 아니면 같은 칸에 적는다. 제품 상수는 근거 번호를, 고정 예외는 사유(법령·보안·데이터 무결성)를 함께 적고 '끌 수 없음' 으로 표시한다.
- AI 가 값을 만드는 패턴은 결정 117 의 제안 → 승인 → 반영 → 감사 경로(AIN-08)를 거친다. 바로 저장하는 패턴은 없다.
- 데이터는 기존 엔터티 한 곳에 두고 화면은 보기로만 나눈다(레이어 분리 원칙). 사본을 만드는 패턴은 살아 있는 보기로 바꿨다.
- 창 배치·크롬은 `plan/09_화면설계/11_창배치_스냅레이아웃.md`(ADR-099)가 정본이다. 11 과 겹치는 패턴(UX-69~72)은 11 을 따르고 차이만 적는다.
- 기존 결정과 충돌하면 기존 결정을 따른다. 충돌이 있어 바꾼 내용은 각 행 '옵션화' 칸과 18a~18d '충돌 결정' 칸에 있다.

## 4. 저장 보기 화면 규칙(UX-29 상세)

18a §5 가 같은 저장 단위로 묶자고 제안한 네 가지(D1-05 보기·D1-24 개인 필터 보기·ISS-12 저장 필터·UX-19 이해관계자별 저장 뷰)는 저장 보기 한 단위다. 저장 보기의 데이터와 계약은 공통 기반 `plt` 가 소유한다(`../08_데이터모델/plt.md` §3.9 `saved_view`, `../10_API설계/plt.md` §8, D-523). ISS-12 저장 필터와 대시보드 위젯은 그 계약을 쓰는 쪽이다. 저장 단위·공유 범위·링크 권한의 기능 규칙은 PLT-01 블록(`../06_기능목록/21_기능요건상세_부록/a05_PLT.md`)이 정본이다(01/18 §6 M-01). 이 절은 화면에서 보이는 동작만 정한다.

- 보기 하나에 필터 값·표 열·정렬·그룹·보기 종류(목록·보드·간트 등)가 함께 저장된다. 보기를 바꿔도 데이터는 바뀌지 않는다.
- 공유 범위는 등록된 범위 종류(53 §5.4, 모듈 선언서가 등록) 가운데 그 화면이 허용한 것이다. 화면마다 허용하는 기본 범위 집합은 `plt` 의 설정 키 기본값이 정한다. 만든 사람의 권한 안에서만 범위를 넓힐 수 있다.
- 공유 링크는 보기 설정만 전달하고 권한을 주지 않는다(UR-04).
- 저장 뒤 값을 바꾸면 이름 옆에 '변경됨' 표시를 붙이고, 저장·다른 이름 저장·되돌리기를 고른다.
- 활성 필터 수와 필수 필터를 표시한다. NAV 는 필터 시트 맨 위에 적용 개수를 보인다.
- 알림 분할 탭(UX-53)·리마인더 위젯(UX-83)은 이 보기를 그대로 쓴다.
