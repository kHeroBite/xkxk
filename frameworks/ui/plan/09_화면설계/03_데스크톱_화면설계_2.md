# 데스크톱 화면 설계 2 (화면별 열림 방식·설정 값 출처 표시)

> `03_데스크톱_화면설계.md` 가 300줄 규칙에 닿아 나눈 연속 분할이다. 절 번호는 본 파일과 이어진다(§8~§11). 머리의 공통 참조와 설정 키 규칙은 본 파일을 따른다.

## 8. 화면별 기본 열림 방식

- 대상 화면과 화면의 단계는 `02_메뉴구조.md`(생성물, 원천 `../_build/menu_data.py`)가 정본이다. 화면별 기본 열림 방식은 `menu_data.py` 의 '데스크톱 열림' 열(생성물 `메뉴구조.csv`)이 정본이고 이 절은 다시 적지 않는다. 이 절은 기본 크기·배치와 주요 구성만 둔다.
- 화면의 단계는 그 화면에 묶인 기능 가운데 가장 이른 단계다. 화면 안 영역은 그 영역 기능의 단계부터 켜진다. 기능의 단계는 기능 등록부(`../06_기능목록/기능목록.csv`) 한 곳에 있다.
- 열림은 MDI 기준이다. DOCK 에서는 문서 탭, 대화면 NAV 에서는 콘텐츠 영역으로 연다.
- 기본 크기는 1280×800 이상 화면을 기준으로 정한 화면 설계 값이다. 사용자 레이아웃이 있으면 그 값을 쓴다. 화면 안 세부 배치는 본 개발 화면 설계에서 정한다.
- 화면이 보이는지는 `../05_아키텍처/30_Pd_회사별_항목정책_옵션화_설계.md` §3 의 표시 판정 한 식을 따르고, 판정 순서의 정본은 `../05_아키텍처/32_Pd_모듈화_조립구조_설계.md` §8 이다.
- 그 식에 따라 테넌트 허용에 없는 모듈의 화면은 숨기고(`ui.screen.not_entitled_display`), 기능 게이트가 닫힌 화면은 잠금 표시와 안내를 보인다(`ui.screen.gate_closed_display`). 회사가 끈 화면과 권한이 없는 화면은 메뉴에서 숨긴다.
- 화면 하나가 여러 모듈의 데이터를 묶으면 소유 모듈 하나가 화면을 갖고 다른 모듈은 화면 확장 자리로 기여한다. 기여 모듈이 테넌트 허용에 없으면 그 영역만 빠진다(30 §3·§8).
- pd-admin 화면(SCR-IMP-03·SCR-ADM-05·SCR-ADM-07)은 이 앱 메뉴에 없다. pd-admin 화면의 자리는 `../05_아키텍처/05_제품구성_시스템메뉴.md` 다.

### 8.1 설정 값 출처 표시

- 설정 값 출처 표시 규칙(값 층 다섯·상속과 지정 토글·제약원 잠금·되돌리기·영향 대상 미리보기)은 모든 폼팩터 공통이라 `01_화면설계_공통원칙.md` §8-4 가 정본이다. 데스크톱에서 이 규칙을 쓰는 화면은 SCR-LIC-01·SCR-ADM-01 과 항목 정책 화면, 개인 설정 화면이고 새 화면·기능 ID 는 없다.

## 9. 태블릿 앱 차이 (같은 셸, DOCK 기본)
- 기본 방식은 DOCK 이다. 핀치로 문서 창 안을 확대하고, 측면 패널은 단일 탭이다(ADR-041). 터치 대상 최소 크기는 `06_모바일_화면설계.md` 기준을 따른다.
- 창 폭이 `ui.layout.compact_width_dp` 미만(접힘·화면 분할)이 되면 스마트폰 NAV 로 자동 전환한다(06 문서).

## 10. 설정 키 (이 문서에서 처음 쓰는 키)

키 이름은 후보다. 값 꼴·기본값·범위·값 분류·허용 층의 선언은 `../10_API설계/plt_2.md` §12.1 이다. 이 표는 키의 뜻만 적는다. 끌기 중 가벼운 크롬의 키는 `01a_화면설계_공통원칙_끌기경량크롬.md` §3 에 있다.

| 키 | 뜻 |
|---|---|
| `ui.mdi.min_grab_dp` | MDI 창 잡을 곳 최소 폭(하한의 사유는 공통원칙 §4.3) |
| `ui.mdi.min_visible_percent` | MDI 창 잔존 비율, 0 이면 잡을 곳 규칙만 |
| `ui.mdi.offscreen.min_grab_overlap_dp` | 메인 창 크기 변화 뒤 MDI 창을 옮길지 가르는 잡을 곳 문턱(가로·세로) |
| `ui.mdi.tab_join.source_opacity` | 합류 표적 위에서 끄는 창의 불투명도 |
| `ui.display.selected_monitor` | 고른 모니터(OS 장치 이름, 저장 위치 = 기기) |
| `ui.display.change_settle_ms` | 모니터·메인 창 크기 변경 뒤 자동 복구 점검까지의 조용 시간 |
| `ui.window.offscreen.strip_height_px` | 안 보임 판정에 쓰는 창 위쪽 띠 높이 |
| `ui.window.offscreen.min_overlap_x_px` | 그 띠가 작업 영역과 겹쳐야 하는 가로 최소 |
| `ui.window.offscreen.min_overlap_y_px` | 그 띠가 작업 영역과 겹쳐야 하는 세로 최소 |
| `ui.window.cascade.origin_offset_px` | 독립 창 기본 위치의 작업 영역 왼쪽 위 들여쓰기 |
| `ui.window.cascade.step_px` | 겹칠 때 독립 창 계단 간격 |

- 03 §5 의 안 보임 판정은 이 표의 `ui.window.offscreen.*` 세 키를 쓰고, 03 §7.2 의 독립 창 기본 위치는 `ui.window.cascade.*` 두 키를 쓴다.
- 범위 밖 값은 범위 안으로 맞춘다. 값이 없으면 기본값으로 읽는다.

## 11. 개정 이력

- 2026-11-18. 측정 회차 기록·시험 도구 이름·구현 클래스 이름·결함 수정 경위를 판정 보고서 부록과 `poc/ui` 문서로 옮기고 동작과 판정 기준만 남겼다.
- 2026-11-18. 셸 패널 목록을 패널 자리와 모듈 등록으로 바꿨다. 로그인 화면의 서버군 선택을 지우고 계정의 테넌트로 서버군을 정하는 규칙(06 §6.2)을 따랐다.
- 2026-11-18. PoC 속성 이름이던 설정 키를 `ui.*` 꼴(후보)로 바꿨다. 설정 상속 표시를 값 층 다섯 개의 출처 표시 규칙으로 넓혔다. §8 이후 절을 이 파일로 나눴다.
- 2026-11-11. 제목 줄(탭 줄) 높이를 설정으로 바꿨다. 값은 공통원칙 §2-1 에 있다.
- 2026-11-10. MDI 창 잔존 비율을 다시 두고 잡을 곳 규칙을 그 하한으로 남겼다(공통원칙 §4.3).
- 2026-11-08. MDI 창 잡을 곳 하한을 두고 버튼만 남는 상태를 금지했다.
