# 16. 개인 플래너(별별플래너)·전환 유도 화면 설계 (REQ-94, 결정 125·126)

> 상태 설계 정본(결정 125·126, ADR-109)
> 근거 D 는 D-318~D-328 이다(상태는 `../90_결정관리/01_결정대기_부록/d318_결정125_확인대기.md`). 값은 설정 키로 둔다(ADR-089). 키의 값 분류·허용 층·기본값은 10 문서 설정 키 절이 정본이고(§7) 이 문서는 키 이름만 인용한다. 키가 없는 수치는 후보다.
> 이 문서는 화면 배치·흐름의 정본이다. 기능 규칙은 기능 부록이 정본이다 — COL-12·COL-13·COL-16·COL-17(`../06_기능목록/21_기능요건상세_부록/a16_COL_2.md`), PLT-09(`../06_기능목록/21_기능요건상세_부록/a05_PLT.md`), LIC-09(`../06_기능목록/21_기능요건상세_부록/a03_LIC.md`), PRJ-07(`../06_기능목록/21_기능요건상세_부록/a07_PRJ_2.md`). 부록과 다르면 부록을 먼저 고치고 이 문서를 맞춘다.
> 규모 모드 0단계 개인 모드(Personal)의 메뉴 노출 규칙은 `12_간편입력_규모적응_화면설계.md` §2 가 정본이고 이 문서는 고치지 않는다. 화면 공통 규칙은 `01_화면설계_공통원칙.md` 를 참조만 한다.
> 새 화면 ID·메뉴 ID 는 이 문서가 부여하지 않는다. 기존 SCR 은 재사용하고, 새 화면은 화면 이름만 둔다(§8). 메뉴 정본(`02_메뉴구조.md`·`메뉴구조.csv`) 등재는 TODO-150 이다.

## 0. 결론

- **플래너는 제품이 아니라 진입 구성이다.** 진입 구성은 같은 Pd 제품 위의 화면 구성과 배포 이름이다. 같은 Pd 클라이언트 코드·같은 pd-server·같은 데이터 구조를 쓰고 `pd_pms` 매니페스트 위에서 돈다(`../05_아키텍처/22b_Pd_회사운영플랫폼_솔루션카탈로그.md` §7). 배포 이름은 별별플래너(`**planer`, 가칭 — `**` 는 별표 두 개이며 '별별' 로 읽는다, D-323)다. 내부 상태는 요금제 Free + 규모 모드 0단계 Personal 고정이고 새 요금 등급은 없다(125-6).
- **플래너 화면은 Pd 의 기존 화면을 개인용으로 묶은 것이다.** 할 일·일정·일정표·알림·아이디어 스케치·계산기·지도·여행 계획·수강표·공부 계획을 새 기능 ID 없이 기존 기능에 매핑한다(125-7, §2).
- **전환 깔때기는 플래너(무료) → Pd Free 전환 → Professional 유료 전환 3단이다(125-8).** Pd Free 전환은 같은 테넌트라 옮길 데이터가 없고 진입점·메뉴 노출만 바뀐다(§4). 유료 전환은 기존 결제 흐름을 그대로 쓴다(§5).
- **전환 안내는 조용하게 한다.** 트리거가 생겼을 때 안내 카드 1장, 주 1회 이하, 사용자가 끌 수 있다(D-325). 강제 팝업·속임수 화면 금지는 제품 상수이고 회사 층에서 바꾸지 못한다(§3.3).

| 영역 | 내용 | 기능 |
|---|---|---|

- 홈 위젯 구성은 `ui.planner.widgets` 다(§7).
- 스마트폰 NAV 하단 탭은 오늘·일정·할 일·노트·더보기 5개(후보)다. 탭 배분은 `06_모바일_화면설계.md` §2.1 규칙(후보, 데이터로 두어 코드 수정 없이 바꿈)을 따르고, 하단 탭에 못 넣은 화면은 더보기로 넘기며 숨기지 않는다(같은 문서 §2 도달 100%).

### 1.1 유틸 제공 두 형태 (결정 126, D-327)

- 계산기 같은 유틸은 ① **위젯**(플래너 홈·Pd 대시보드에 놓는 카드)과 ② **독립 새 창** 두 형태로 제공한다. 새 창은 폼팩터별로 데스크톱 MDI 문서 창·SDI 분리 창, 웹은 관리형 창(`04_웹_화면설계.md` 차이표), 태블릿 DOCK 은 본문 영역, 스마트폰 NAV 는 전체 화면 페이지로 연다. 위젯의 [새 창으로 열기] 단추와 명령 팔레트 결과의 [창으로 열기] 로 옮겨 가며, 두 형태는 같은 계산 함수·같은 입력 기록을 쓴다.
- 명령 팔레트 인라인 계산은 보조 경로로 남긴다(PLT-09 명령 팔레트, 결과 표시·복사).
- 유틸은 새 기능 ID 를 받지 않고 서브 ID 로 구분한다. 계산기는 `PLT-09-U1` 이고 다음 후보(단위 변환·타이머)는 미발급이다. 서브 ID 규칙 정본은 `09_메뉴ID_규칙.md` §10, 기능 규칙 정본은 a05_PLT 의 PLT-09 블록이다.
- 위젯 표시는 `ui.planner.utility.widget`, 새 창 허용은 `ui.planner.utility.window`, 제공 유틸 목록은 `ui.planner.utility.list` 다(§7).

- SCR-COL-06·SCR-COL-08 은 메뉴 정본에 화면 ID 가 있고 화면 자체가 아직 후보다(`02_메뉴구조.md`). 화면 ID 는 바뀌지 않는다(D-496).
- 지도는 I-49 후보(공급자 미정 — D-326, TODO-151)다. 사용은 `plt.map.enabled`, 공급자는 `plt.map.provider` 다(§7). 지도를 끄거나 공급자 장애면 장소는 텍스트 목록만 보이고 여행 계획 화면은 계속 동작한다. 단말 위치는 사용자 동의 없이 수집하지 않는다(고정 예외 — 법령·보안, 법령 확인 TODO-151).
- 개인 팩 템플릿(여행 계획·수강표·공부 계획)은 사용자가 복사해 편집하는 시작본이다(D-328). 템플릿 정본은 `../03_개발범위/09_업종팩_확대_기본템플릿.md` 다.
- 화면 이름은 '프로젝트 관리' 용어 대신 할 일·일정·노트를 쓴다(12 §2.4, 표시명은 언어 팩).

### 3.2 빈도·끄기

- 트리거가 생겨도 카드는 1장만 보인다. 빈도 상한은 `ui.planner.upgrade_prompt.max_per_week` 다(D-325). 같은 주에 다른 트리거가 생기면 다음 주로 미룬다.
- 트리거 목록은 `ui.planner.upgrade_triggers` 이고 위 표는 그 기본 목록의 화면 동작이다. 안내 자체 켬·끔은 `ui.planner.upgrade_prompt.enabled` 이고 허용 층에 사용자 층이 있어, 사용자는 카드의 [다시 보지 않기] 또는 설정에서 끌 수 있다.
- 카드는 화면 하단 또는 홈 목록 사이에 놓이는 인라인 카드이며 작업을 막지 않는다. 트리거 동작 자체(예 간트 열기)는 잠금 표지와 [Pd 로 열기]만 보이고 기존 데이터 열람은 막지 않는다.

### 3.3 금지 패턴 (제품 상수)

- 강제 팝업(닫을 수 없는 전면 화면·작업을 막는 모달), 닫기 단추 숨기기·작게 만들기, '아니요, 저는 정리를 싫어합니다' 같은 죄책감 문구, 무료 기능을 몰래 잠그기, 카운트다운으로 서두르게 하기, 해지·되돌리기 경로 숨기기는 금지한다.
- 값 분류는 제품 상수다(근거 결정 125·D-325 — 조용한 안내, 사용자가 끌 수 있음). 고정 예외(법령·보안·데이터 무결성)가 아니라 사용자가 정한 제품 정책이므로 운영 시스템 층에서만 정하고 회사 재정의가 없다. 나라별 속임수 화면 규제는 법령 근거로 쓰지 않았다(미확인). 안내 문구·빈도만 회사·사용자 층의 값이다.
- 키는 `ui.planner.upgrade_prompt.forbidden_patterns` 이고 선언은 10 plt_2.md §12.1 이다.

## 5. Professional 유료 전환 화면 (LIC·빌링 I-19)

- 요금제 비교·결제는 기존 요금제 화면(SCR-LIC-01 회사·요금제·AI 크레딧)과 빌링 흐름(I-19)을 그대로 쓴다. 플래너 전용 결제 화면은 만들지 않는다.
- 가격·한도 숫자는 이 문서에 쓰지 않는다. 정본은 `../03_개발범위/20c_Pd_솔루션기획안_요금_패키징_AI과금.md` §6.2.1(개인 모드 요금, 결정 124)과 같은 문서의 결정 125 플래너 깔때기 절이다.
- 플래너에서 바로 [요금제 보기]를 누르면 Pd Free 전환(§4)을 먼저 거치지 않고 결제까지 갈 수 있다. 결제가 끝나면 Pd Free 전환과 같은 효과(Personal 고정 해제)가 함께 적용된다.

## 7. 설정 키

이 화면이 읽는 키다. 값 분류·허용 층·기본값의 정본은 '선언 자리' 칸의 10 문서 설정 키 절이고 이 표는 값을 다시 적지 않는다. `ui.planner.*` 는 횡단 접두 `ui` 의 키이고 해석은 `plt` 가 맡는다(유틸 위젯은 Pd 대시보드에도 놓이므로 키 머리를 플래너 진입 구성에 묶지 않는다).

| 화면 동작 | 키 | 선언 자리 |
|---|---|---|
| 전환 안내 켬·끔 | `ui.planner.upgrade_prompt.enabled` | `../10_API설계/plt_2.md` §12.1 |
| 전환 안내 빈도 | `ui.planner.upgrade_prompt.max_per_week` | 위와 같다 |
| 전환 트리거 목록 | `ui.planner.upgrade_triggers` | 위와 같다 |
| 플래너 홈 위젯 | `ui.planner.widgets` | 위와 같다 |
| 유틸 위젯 표시·새 창 허용 | `ui.planner.utility.widget`·`ui.planner.utility.window` | 위와 같다 |
| 제공 유틸 목록 | `ui.planner.utility.list` | 위와 같다 |
| 저장 한도 안내 임계(§3.1) | `ui.planner.storage_warn_pct` | 위와 같다 |

- 진입 구성 이름·배포 값(별별플래너, 별도 스토어 등록·같은 코드)은 설정 키가 아니라 배포 구성 값이다(D-323).
- 제품 상수: §3.3 금지 패턴(결정 125·D-325).
- 고정 예외: 단말 위치 무동의 수집 금지(법령·보안), 전환·되돌리기 때 데이터 삭제 금지(데이터 무결성).
