# 15. 외부 참여·공유 링크 화면 설계 (REQ-88·91·92, 결정 124)

> 상태 설계 정본(결정 124, ADR-108)
> 값은 설정 키로 둔다(ADR-089). 키의 선언·값 분류·허용 층·기본값은 키를 가진 모듈의 10 문서 '설정 키' 절이 정본이고 이 문서는 키 이름만 인용한다(§6). 키 이름은 후보다.
> 이 문서는 화면 배치·흐름의 정본이다. 기능 규칙은 기능 부록이 정본이다 — IAM-12(게스트 초대·종료 조건·유예·관리 조치, `../06_기능목록/21_기능요건상세_부록/a01_IAM_2.md`)·APR-08(공유 링크)·APR-11(교차 테넌트, `../06_기능목록/21_기능요건상세_부록/a11_APR.md`)·LIC-05(게스트 계정 포함 수, `../06_기능목록/21_기능요건상세_부록/a03_LIC.md`)·ADM-09(발급 현황 모니터링, `../06_기능목록/21_기능요건상세_부록/a04_ADM.md`). 부록과 다르면 부록을 먼저 고치고 이 문서를 맞춘다.
> 이메일 일회용 코드 입력 컴포넌트는 `14_로그인_가입_통합진입_화면설계.md` §2(S3)·§6·§10 을 재사용하고 이 문서는 고치지 않는다. 화면 공통 규칙은 `01_화면설계_공통원칙.md` 를 참조만 한다.
> 새 화면 ID·메뉴 ID 는 이 문서가 부여하지 않는다. 메뉴 정본(`02_메뉴구조.md`·`메뉴구조.csv`)이 등재할 때 부여하며 §7 은 화면 이름만 둔다.

## 0. 결론

- **외부 사람이 들어오는 길은 3경로다.** ① 다른 테넌트 Pd 계정 보유자 초대(APR-11 교차 테넌트) ② 계정 없는 사람에게 정식 좌석 또는 게스트 계정 발급 ③ 공유 링크(보기 전용)다(124-4). 초대 대화상자는 대상 이메일에 계정이 있는지 보이지 않는다. ① 과 ② 의 갈림은 받는 사람이 초대를 수락할 때 서버가 정한다(D-547, §1).
- **세 경로 모두 종료 조건이 필수다.** 초대는 기간 또는 마일스톤 종료 조건(REQ-88), 공유 링크는 만료일이 없으면 확정 단추가 켜지지 않는다. 이 필수 조건은 고정 예외(보안)다. 끝없는 외부 접근을 막기 위함이다.
- **공유 링크 열람은 비로그인 화면이다.** 기본 접근 방식은 이메일 일회용 코드 인증 열람이고 내용은 읽기 전용이다(§3).
- **발급은 한 화면에서 본다.** 회사는 SCR-APR-03 '외부 참여 현황' 영역, 운영사는 pd-admin SCR-ADM-05 사용량 현황에서 3경로 발급 현황을 모니터링한다(§4, 124-10).

## 1. 초대 대화상자 (IAM-12·APR-11)

| 순서 | 화면 요소 | 규칙 |
|---|---|---|
| ① | 대상 이메일 입력 | 형식만 확인한다. 계정이 있는지·다른 테넌트에 속하는지는 어떤 문구·단추 상태로도 보이지 않는다(14 §6, 고정 예외 — 보안) |
| ② | 참여 방식 | '참여 초대'와 '공유 링크 만들기'(§2) 가운데 고른다. 참여 초대는 받는 사람이 계정이 없을 때 줄 발급 종류('정식 좌석'·'게스트 계정')를 함께 고른다 |
| ③ | 롤·권한 | 게스트 롤 템플릿(IAM-12)에서 고른다. 초대자 권한보다 넓은 권한은 목록에 없다(고정 예외 — 데이터 무결성) |
| ④ | 종료 조건(필수) | 기간(종료일) 또는 마일스톤 1개. 비어 있으면 '초대' 단추가 꺼져 있다 |
| ⑤ | 잔여 표시 | 게스트 계정을 고르면 포함 수 대비 사용 수를 보인다. 경고색 임계는 `iam.guest.warn_pct` 다 |

- **경로는 수락 때 갈린다(D-547).** 받는 사람이 초대를 수락할 때 이미 다른 테넌트 Pd 계정을 가졌으면 교차 테넌트 참여(APR-11)가 되고 좌석·게스트 계정 수를 쓰지 않는다. 계정이 없으면 ② 에서 고른 발급 종류로 계정을 만든다. 초대자는 수락 결과를 §4 현황의 행으로만 본다.
- 게스트 경로의 초대는 `iam.guest_invite`, 게스트 멤버십은 `iam.guest_membership`, 초대로 생긴 역할 부여는 `iam.role_binding`(`invite_id`)에 남는다(08 iam.md §3.4·§3.8).
- 게스트 계정 잔여가 0 이면 '게스트 계정' 발급 종류를 잠그고 추가 구매 안내와 '공유 링크로 보기만 허용' 대안을 함께 보인다. 수락 때 상한에 닿은 경우의 오류 코드는 `lic` 의 게스트 계정 수 초과 코드다(`../10_API설계/lic.md` 오류 절).
- 초대 요청에는 서버가 속도 제한과 감사 기록을 건다(D-547).
- 마일스톤 종료 조건의 예정일이 지난 뒤 처리는 `iam.guest.condition_overdue_action`(자동 회수·알림만)이다. 대화상자 아래에 지금 값을 한 줄로 보인다.
- 개인 모드(Personal) 테넌트에서 타인 초대를 허용하지 않으면(`lic.personal.invite_allowed`) 초대 단추 자체를 숨긴다(`12_간편입력_규모적응_화면설계.md` §2.4).
- 초대를 확정한 뒤 초대 링크 옆에 'QR 보기' 를 둔다(결정 137, `../05_아키텍처/47_Pd_생체인증_QR_설계.md` §8·§10).

## 2. 공유 링크 발급 대화상자 (APR-08)

| 항목 | 선택지 | 기본값·규칙 |
|---|---|---|
| 공유 범위 | 등록된 공유 대상 종류(프로젝트 전체·화면·뷰·문서 등) | 공유 대상 종류는 등록형이다. 대상을 가진 모듈이 선언서로 종류를 올리고 대상 확인 포트 `portal.port.target` 을 구현한다(08 apr.md `share_link.scope_kind`, 이전 예정 → `portal`). 화면은 테넌트 허용에 든 모듈이 올린 종류만 보인다. 지금 열린 화면이 기본이고 발급자 권한보다 넓은 범위는 고를 수 없다(고정 예외 — 데이터 무결성) |
| 접근 방식 | 공개 링크(선택 비밀번호) / 이메일 일회용 코드 인증 열람 / 지정 이메일만 | 허용 단계 `portal.share_link.access_modes`, 기본 단계 `portal.share_link.default_access_mode`, 공개 링크 허용 `portal.share_link.public_allowed` |
| 만료일(필수) | 날짜 선택 | 기본 `portal.share_link.default_expiry_days`, 상한 `portal.share_link.max_expiry_days`(D-310) |
| 비밀번호 | 공개 링크일 때만 입력칸 | 선택 |
| 지정 이메일 | 지정 이메일만일 때 목록 입력 | 1개 이상 필수 |
| 제외 필드 | 원가·계약 금액 체크(기본 제외) | 급여·인사 민감 필드는 고정 제외로 체크칸이 없다(보안 예외) |

- 확정하면 링크 주소와 '복사' 단추, 만료일, '회수' 단추를 보인다. 토큰 원문은 이 순간에만 보이고 다시 볼 수 없다(토큰 해시 저장, 보안).
- 'QR 보기' 는 '복사' 단추 옆에 두며 토큰 원문과 같은 순간에만 보이고 다시 볼 수 없다. 주소 길이가 `plt.qr.dense_notice_chars` 를 넘으면 'QR 이 촘촘합니다' 안내를 함께 보인다(결정 137, 47 §10).
- 프로젝트당 링크 수는 개인 모드(Personal)가 `lic.personal.share_links_per_project`, 회사 테넌트가 `portal.share_link.max_per_project` 다. 한도에 닿으면 발급 단추 대신 기존 링크 보기·회수를 보인다. 오류 코드는 `../10_API설계/apr.md` 오류 절(공유 링크, 이전 예정 → `portal`)이다.
- 공유 링크의 소유 모듈은 선택 모듈 `portal` 이다(`../05_아키텍처/48_Pd_연동설계_총괄_계약등록부.md` §3.1, D-522). `portal` 이 테넌트 허용에 없으면 '공유 링크 만들기'와 §3 열람 화면을 그리지 않는다(추정 — 48 의 조립 규칙에서 읽은 판단).

## 3. 공유 링크 열람 화면 (비로그인)

| 단계 | 화면 | 규칙 |
|---|---|---|
| ① 진입 | 링크 주소 열기 → 회사 로고·링크 제목·만료일 | 로그인 화면으로 보내지 않는다 |
| ② 이메일 입력 | 이메일 칸 1개·'코드 받기' | 이메일 일회용 코드 방식과 지정 이메일 방식에서만 보인다. 공개 링크는 비밀번호 칸(설정 시)으로 바로 간다 |
| ③ 일회용 코드 | 코드 칸 1개·재발송·남은 시간 | 14 의 S3 코드 입력 컴포넌트를 그대로 쓴다(붙여넣기 허용·숫자 키보드·`aria-live` 알림) |
| ④ 열람 | 공유 범위 안 화면만 읽기 전용, 상단 '읽기 전용 · 만료 YYYY-MM-DD' 띠 | 편집·내려받기·댓글 단추 없음. 제외 필드는 칸 자체가 없다 |
| ⑤ 세션 | 코드 인증 뒤 열람 세션 유지 | 유지 시간 `portal.share_link.session_ttl_hours`(D-310). 끝나면 ② 로 돌아간다 |

- 안내 문구는 고정이다. 만료·회수·대상 삭제는 모두 '이 링크는 더 이상 열 수 없습니다.' 하나로 보이고 사유를 구분하지 않는다. 오류 코드는 `../10_API설계/apr.md` 오류 절이 정본이다.
- 지정 이메일 목록에 없는 이메일도 ③ 까지 같은 화면이 뜨고 코드는 보내지 않는다. 목록 존재 여부·계정 존재 여부를 드러내지 않는다(14 §6 계정 열거 방지 규칙과 같다).
- 공개 링크 허용을 끈 회사의 공개 링크는 ① 에서 위 고정 문구를 보인다.
- 모든 열람은 열람 로그(시각·IP·이메일)에 남는다. 화면 아래에 '열람 기록이 남습니다' 고정 문구를 둔다. 보존 기간은 `portal.share_link.access_retention_days`(D-310)이고 법령 확인은 TODO-147 이다.

## 4. 외부 참여 현황 (SCR-APR-03 영역, ADM-09 확장)

| 탭 | 열 | 동작 |
|---|---|---|
| 교차 테넌트 참여자 | 이름·소속 회사·프로젝트·권한·종료 조건·남은 기간 | 권한 변경·회수 |
| 게스트 계정 | 이메일·상태(활성·유예·비활성)·유효 초대 수·멤버십 만료일·유예 종료일 | 만료·비활성·재활성·소멸·재생성(업체관리자, 확인 대화상자 + 감사) |
| 공유 링크 | 제목·공유 범위·접근 방식·발급자·만료일·열람 수·상태(활성·만료·회수) | 회수·만료일 앞당기기·열람 로그 보기 |

- 상단 요약 띠는 게스트 계정 수 / 포함 수, 7일 안 만료 예정 건수, 활성 공유 링크 수다. 게스트 유예 일수는 `iam.guest.grace_days` 이며 유예 중인 게스트는 수에 들어간다.
- 열람 로그는 링크별 시각·IP·이메일·결과 표이고 내보내기는 감사 권한자만 한다.
- pd-admin SCR-ADM-05 는 테넌트별 같은 세 수치(교차 테넌트 참여자 수·게스트 계정 수·공유 링크 수와 열람 수)를 집계로만 보인다. 개별 이메일은 보이지 않는다(테넌트 경계).

## 5. 폼팩터

| 폼팩터 | 발급(§1·§2) | 열람(§3) | 현황(§4) |
|---|---|---|---|
| 데스크톱 앱(MDI) | 대화상자(모달) | 앱 안에서 열지 않고 기본 브라우저로 연다 | MDI 문서 창 |
| 웹·모바일 웹 | 대화상자 | 우선 대상(반응형 1단) | 표 → 좁은 폭은 카드 목록 |
| 모바일 앱(스마트폰 NAV) | 전체 화면 시트 | 기본 브라우저로 연다 | 더보기 → 외부 참여 |

- 열람 화면은 웹·모바일 웹이 우선이다. 받는 사람은 앱이 없다고 본다.
- 받는 사람이 모바일 앱이 있으면 QR 로 열 수 있다(47 §9). 앱이 없으면 폰 기본 카메라가 링크를 연다(추정, 미실측).
- QR 표시는 데스크톱·웹·모바일 공통이고 QR 스캔은 Android 모바일 앱만 한다(iOS 는 실측 뒤).

## 6. 설정 키

이 화면이 읽는 키다. 값 분류·허용 층·기본값은 '선언 자리' 칸의 10 문서 설정 키 절이 정본이고 이 표는 값을 다시 적지 않는다.

| 화면 동작 | 키 | 선언 자리 |
|---|---|---|
| 공유 링크 접근 방식(허용·기본)·공개 링크 허용 | `portal.share_link.access_modes`·`portal.share_link.default_access_mode`·`portal.share_link.public_allowed` | `../10_API설계/apr.md`(이전 예정 → `portal`) |
| 기본 만료·최대 만료 | `portal.share_link.default_expiry_days`·`portal.share_link.max_expiry_days` | 위와 같다 |
| 열람 세션·열람 로그 보존·프로젝트당 링크 수 | `portal.share_link.session_ttl_hours`·`portal.share_link.access_retention_days`·`portal.share_link.max_per_project` | 위와 같다 |
| 개인 모드 프로젝트당 공유 링크 수·타인 초대 | `lic.personal.share_links_per_project`·`lic.personal.invite_allowed` | `../10_API설계/lic.md` |
| 게스트 경고 임계·유예 일수·종료 조건 경과 처리 | `iam.guest.warn_pct`·`iam.guest.grace_days`·`iam.guest.condition_overdue_action` | `../10_API설계/iam.md` |
| QR 스캔 사용·스캔 링크 허용 방식·촘촘함 안내 길이 | `plt.qr.scan.enabled`·`plt.qr.link_allowlist_mode`·`plt.qr.dense_notice_chars` | `../10_API설계/plt.md`(값의 정본은 05/47) |
