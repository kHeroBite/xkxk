## 2.1 실측 방법 (AutomationBridge 인자 — odev-3 구현 기준)

- 실행 순서는 load-layout → open → layout → move-all(60프레임 분할) → sdi → cmd → screenshot → save-layout → exit-after → perf-out 이다.
- `--cmd` 는 close-others·close-all·minimize-all·restore-all·next·prev·redock-all·grid-exercise·gantt-exercise 를 쉼표로 이어 받는다. 중복 확인은 `--open grid:2 --dedupe` 로 한다.
- perf JSON 키는 startup_ms(=first_frame_ms), open_ms, open_p95_ms, frame_p50/p95/p99_ms, doc_count, mode, grid_sort_ms, grid_sort_render_ms, phases[](move-all = PERF-02 근사)다.
- 스크린샷은 실행 1회당 주 창 1장이다. 플로팅 SDI OS 창은 PrintWindow 로 따로 캡처했다.
- MDI-12 는 인자로 발동할 명령이 없다. 화면 노출이 필요해 포그라운드 시험으로 남겼다.

| 주소·포트 | `http://localhost:5959/` 다. 포트가 사용 중이면 +1씩 다음 포트를 시도한다(Program.cs 주석 기준 5959~5964). | 127.0.0.1 만 바인딩하고, 실제 포트는 기동 시 파일·로그로 알린다. |

| 결과 형식 | JSON(UTF-8, 들여쓰기)이다. `success`·`error` 필드와 HTTP 상태 코드를 쓴다(예: 404 + `{success:false,error:...}`). 스크린샷은 `/api/screenshot/download` 가 PNG 바이트를 직접 준다. | 같은 봉투(`ok`·`error`·`data`)로 통일하고, 바이너리는 별도 경로로 준다. |
| 비활성 조작 | `noactivate=1`(쿼리 또는 본문)을 주면 창 열기·복원·최소화·최대화·이동·크기 변경이 전경을 뺏지 않는다(사이클166). `/api/window/place` 는 항상 SWP_NOACTIVATE 다. `--bg` 기동이면 메인 창도 활성화 없이 뜬다. | 모든 명령을 기본 비활성(전경 비탈취)으로 한다. |
| 시험 스킬의 사용 방식 | `otest_winforms_bg` 는 조작 사다리 **L0(앱 내장 자동화 API) → L1(UIAutomation) → L2(창 메시지)** 순서로 내려간다. L0 수단은 각 프로젝트 INFRA.md 에만 둔다. Mars INFRA.md 는 WSL 에서 Windows `curl.exe` 로 `localhost:5959` 를 호출해 헬스체크·종료·로그·스크린샷을 한다. | PD INFRA.md 에 L0 = 원격 제어 채널 사용법(포트·토큰 위치·명령)을 적어 같은 스킬로 시험한다. |

PD 는 Mars 와 다음 네 가지를 다르게 한다. 근거는 모두 보안이다.

| 차이 | Mars | PD | 근거(보안) |
|---|---|---|---|
| 인증 | 없음 | 기동 토큰(기동마다 새로 생성) 헤더 필수 | 같은 PC 의 다른 프로세스·사용자가 앱을 조작하거나 화면·로그를 빼내지 못하게 한다. PD 는 SaaS 고객 PC 에 설치되므로 무인증 채널은 그대로 공격면이 된다. |
| 기본 상태 | 로그인 후 항상 켜짐 | 기본 꺼짐, 명시 옵션·개발 빌드에서만 켬 | 일반 사용자 환경에서는 채널 자체가 없도록 해 노출을 없앤다. |
| 바인드 | `localhost` 접두사 | `127.0.0.1` 만 바인드 | 이름 해석·IPv6·다른 인터페이스로 열릴 여지를 없앤다. |
| CORS | `*` 허용 | 허용하지 않음 | 사용자가 연 웹 페이지의 스크립트가 브라우저를 통해 로컬 채널을 호출하는 공격(교차 출처 요청)을 막는다. |

- 로그인 전 사용 가능은 보안이 아니라 시험 편의(로그인 화면 자동화) 차이다.
- 확인하지 못한 것은 각 라우트의 전체 인자 목록과 응답 필드 전수다. 위 인자는 핸들러 본문의 `data["..."]`·`TryGetValue` 추출 결과의 대표값이다.
